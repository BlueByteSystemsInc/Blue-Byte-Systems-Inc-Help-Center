# Ressources partagées

Ouvrez **PDMPublisher > Settings** et utilisez le groupe **Shared Resources** pour les paramètres réutilisés par la publication et les flux de travail utilitaires.

| Page | Utilisé pour |
| --- | --- |
| [PDM](pdmpublishersolidworks_pdm-settings.md) | Sélectionne le coffre-fort locale utilisée par les fonctions PDM-aware. |
| [Langues](pdmpublishersolidworks_languages.md) | Sélectionne le langage d'interface supplémentaire. |
| [Lieux de fichiers](pdmpublishersolidworks_file-locations.md) | Définit les emplacements supplémentaires utilisés pour trouver des dessins connexes. |
| [Sources extérieures] (pdmpublishersolidworks_external-sources.md) | Conserve des définitions de requêtes SQL Server réutilisables. |
| [Formules avancées] (pdmpublishersolidworks_advanced-formulas.md) | Stocke les expressions nommées pour les noms de fichiers, les dossiers et les propriétés. |

### Formules avancées

![Paramètres avancés des formules](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Advanced_Formulas_Default_Light_100.png)
Les modifications ne sont pas engagées tant que vous n'avez pas sélectionné **OK**. **Cancel** rejette les modifications effectuées depuis l'ouverture de la fenêtre Paramètres. Utilisez [Importer, Exporter et Réinitialiser les paramètres](pdmpublishersolidworks_settings-transfer.md) pour sauvegarder ou déplacer ces ressources.

> [!NOTE]
> Une ressource partagée fournit une définition réutilisable. Les profils et commandes individuels décident toujours s'ils doivent l'utiliser.
