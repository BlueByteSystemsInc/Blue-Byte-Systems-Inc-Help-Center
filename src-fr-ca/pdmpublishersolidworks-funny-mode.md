# Mode drôle

Activez **Enable funny mode** sur l'onglet A propos pour utiliser d'autres messages d'avancement pendant qu'une tâche de publication est exécutée.

Le mode drôle ne change que la formulation du message. Elle ne change pas:

- Fichiers sélectionnés pour le traitement
- Conditions ou quantités
- Formats ou emplacements de sortie
- Performances ou résultats à l'exportation

Désactiver l'option lorsque la formulation standard de progrès est préférée. Le cadre s'applique à la publication ultérieure des emplois.
