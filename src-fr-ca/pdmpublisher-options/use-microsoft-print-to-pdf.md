# Utilisez Microsoft Print To PDF pour enregistrer les PDF

![Utilisez le réglage Microsoft Print To PDF](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-032-property-use-microsoft-print-to-pdf-to-save-pdfs.png)
Utilise le chemin d'imprimante de Windows **Microsoft Print to PDF** lors de la création de PDF.

Utilisez ceci seulement lorsque le chemin d'exportation normal PDF ne correspond pas à vos exigences d'environnement ou de sortie.
