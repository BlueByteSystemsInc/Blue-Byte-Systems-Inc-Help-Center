# Masquer les tâches dans l'explorateur de fichiers

![Cacher la tâche dans le réglage de l'explorateur de fichiers](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-018-property-hide-task-in-file-explorer.png)
Cache la commande de tâches dans le menu de clic droit de l'Explorateur de fichiers PDM.

Par défaut, la tâche est affichée dans l'Explorateur de fichiers sous `Tasks > TaskName`.

Utilisez ceci pour les configurations de tâches qui ne doivent être exécutées qu'à partir de flux de travail contrôlés ou de contextes d'administration.
