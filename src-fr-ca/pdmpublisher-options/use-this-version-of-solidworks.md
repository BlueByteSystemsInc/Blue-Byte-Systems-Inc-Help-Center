# Utiliser cette version de SOLIDWORKS

![Utilisez cette version du réglage SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-034-property-use-this-version-of-solidworks.png)
Sélectionne qui a installé la version SOLIDWORKS devrait exécuter la tâche de publication.

![Déclin de la version SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-dropdown-005-use-this-version-of-solidworks.png)
L'icône SOLIDWORKS est un identifiant visuel. Sélectionnez une année installée sur l'hôte de tâche, ou sélectionnez `Latest` pour utiliser la plus récente installation supportée détectée sur cet ordinateur.
