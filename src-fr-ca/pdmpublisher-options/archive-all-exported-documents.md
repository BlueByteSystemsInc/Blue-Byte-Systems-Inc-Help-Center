# Archiver tous les documents exportés (.zip)

![Archiver tous les documents exportés paramétrant dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox6_Archive_all_exported_documents___zip__Light_100.png)
Crée une archive ZIP contenant les documents exportés.

> [!NOTE]
> Ce réglage est disponible dans les **tâche PDM** et **SOLIDWORKS add-in**.

Utilisez ceci pour les paquets de version, les paquets fournisseurs, ou quand un workflow a besoin d'un fichier pour passer par l'examen.
