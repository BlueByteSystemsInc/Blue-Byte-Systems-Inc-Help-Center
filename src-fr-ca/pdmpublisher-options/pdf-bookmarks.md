# Signets PDF

![PDF paramètre de signets dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Scroll1_Light_100.png)
Définit le motif de signet utilisé dans le PDF fusionné.

> [!NOTE]
> Ce réglage est disponible dans les **tâche PDM** et **SOLIDWORKS add-in**. Les valeurs offertes par le menu Placeholder dépendent du traitement du fichier à partir de PDM ou du document SOLIDWORKS actif.

Les signets facilitent l'examen et la navigation des PDF fusionnés.
