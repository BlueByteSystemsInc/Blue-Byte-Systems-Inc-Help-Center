# Créer une référence du fichier de destination vers le fichier source

![Créer le paramètre de référence](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-010-property-create-reference-from-dest-file-to-source-file.png)
Crée une référence PDM à partir du fichier de destination exporté vers le fichier source.

Cela aide les utilisateurs à retracer une livraison exportée vers le modèle ou le dessin qui l'a créé.
