# Ajouter une table des matières à PDF fusionné

![Ajouter une table de configuration de contenu dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox10_Add_table_of_content_to_merged_PDF_Light_100.png)
Ajoute une table de matières générée à la PDF fusionnée.

> [!NOTE]
> Ce réglage est disponible à la fois dans la sortie **tâche PDM** et **SOLIDWORKS add-in** et dépend de l'assemblage fusionné PDF.

![Personnaliser la boîte de dialogue des colonnes TOC](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_TOC_columns_Default_Light_100.png)
Utilisez ceci avec [Merge Exported PDFs en One Master PDF](merge-exported-pdfs.md). La table de contenu est créée pour le PDF fusionné, et non pour les fichiers PDF séparés.

Paramètres connexes :

- [Merge Exporté PDF dans One Master PDF](merge-exported-pdfs.md) crée le maître PDF qui reçoit la table de contenu.
- [Exporter des références aux formats de fichiers individuellement](export-references-individually.md) est nécessaire lors de la fusion des PDF à partir d'un assemblage.
- [Formulaires de fichiers](file-formats.md) doit inclure `PDF`.
- [PDF Signet](pdf-bookmarks.md) peut ajouter la navigation à l'intérieur du PDF fusionné.
- [Colonnes de table](table-columns.md) contrôle les colonnes utilisées dans les tables PDF générées.
