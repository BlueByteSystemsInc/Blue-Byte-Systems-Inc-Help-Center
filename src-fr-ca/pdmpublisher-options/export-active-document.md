# Document affecté par l'exportation

![Détermination du document actif d'exportation](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-012-property-export-affected-document.png)
Exporte le document touché, qui est le fichier de haut niveau qui a déclenché la tâche PDM.

Désactiver cela seulement lorsque la tâche doit traiter les documents référencés, mais pas le document de haut niveau.
