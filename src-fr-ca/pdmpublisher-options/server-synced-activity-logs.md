# Logs d'activités synthétisés par serveur

![Logs d'activité synchronisés du serveur](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-025-property-server-synced-activity-logs.png)
Envoie les journaux d'activité au serveur afin qu'ils puissent être examinés plus tard pour le support et le dépannage.

Ce paramètre est lié à [Logs d'activités par défaut](turn-on-activity-tracking.md). Activez d'abord les journaux d'activité du coffre-fort afin que la tâche ait des journaux à envoyer.

> [!WARNING]
> Confirmez la politique de votre entreprise avant d'activer les logs synchronisés serveur si les noms de fichiers, les chemins, les noms de variables ou l'historique d'emploi sont considérés comme sensibles.
