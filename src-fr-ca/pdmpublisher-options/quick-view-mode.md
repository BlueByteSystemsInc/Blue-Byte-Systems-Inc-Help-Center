# Mode de vue rapide (dessins seulement)

![Définition du mode vue rapide](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-024-property-quick-view-mode-(drawings-only).png)

Ouvre les dessins en mode vue rapide où supporté. Cela peut réduire le temps de charge pour les opérations d'exportation de dessin seulement.

> [!WARNING]
> Le mode vue rapide utilise la vue de dessin en cache. Il peut ne pas utiliser les dernières données du modèle référencé.

Ne l'utilisez que pour des dessins extrêmement grands où la charge normale de dessin est trop lente.
