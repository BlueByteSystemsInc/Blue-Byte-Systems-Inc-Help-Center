# Colonnes du tableau

![Colonnes de table en PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Scroll1_Light_100.png)
Commandes qui apparaissent dans la table des matières PDF générée.

> [!NOTE]
> Ce réglage est disponible dans les **tâche PDM** et **SOLIDWORKS add-in**.

![Table des colonnes déroulantes dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_TOC_columns_Dropdown1_Light_100.png)
Options:

- `Just Name` ne comprend que le nom du fichier ou de l'élément.
- `Name & Quantity` inclut le nom et la quantité.
- `Custom Columns` utilise les colonnes configurées avec **Customize Table**.

![Personnaliser la boîte de dialogue des colonnes de table](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_TOC_columns_Default_Light_100.png)
Utilisez ceci avec [Ajouter une table de contenu à PDF](add-table-of-content-to-merged-pdf.md).
