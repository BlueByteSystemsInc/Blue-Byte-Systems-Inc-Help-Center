# Variables de carte entre la source et le fichier de destination

![Détermination des variables de carte](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-021-property-map-variables-between-source-and-destination-file.png)
Carte des variables du fichier source vers le fichier de destination généré.

Utilisez ceci lors de l'exportation PDFs ou des fichiers neutres ont besoin de métadonnées pour la recherche, l'approbation ou l'automatisation en aval.

![Dialogue de mappage variable](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-dialog-variable-mapping.png)
Utilisez **Add Mapping** pour ajouter une nouvelle règle source à destination.

Colonnes :

- **Source** est la variable du fichier original.
- **Value** affiche la valeur que PDMPublisher lit depuis le fichier source.
- **Destination** est la variable écrite dans le fichier exporté.

Par exemple, `Source Revision Number` peut être cartographié vers `Revision` afin que le fichier exporté conserve la valeur de révision à partir du fichier source.
