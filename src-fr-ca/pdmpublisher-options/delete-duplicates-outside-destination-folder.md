# Supprimer les duplicatas en dehors du dossier de destination

![Supprimer le réglage des duplicatas](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-011-property-delete-duplicates-outside-the-destination-folder.png)
Supprime les fichiers de sortie dupliqués en dehors du dossier de destination.

Utilisez ceci lorsque la tâche doit garder un emplacement de fichier exporté canonique.

> [!WARNING]
> Examiner ce paramètre avant de l'utiliser dans les coffres-forts où les anciens livrables exportés doivent être conservés aux fins de vérification ou de publication.
