# Activateur de licence hors ligne

Le **PDMPublisher Offline License Activator** (activator.exe) est un utilitaire sécurisé et autonome conçu pour les environnements où la connectivité Internet est restreinte ou interdite.

![activateur hors ligne](https://pdmpublisher.com/help/images/offlineactivator.png)
Cet outil permet aux administrateurs autorisés de consommer une licence PDMPublisher sans exiger :

- Accès à Internet
- Validation en nuage
- Communication HTTP externe
- Télémétrie ou trafic sortant

Il est spécifiquement destiné à:

- Contractants de la défense
- Programmes aérospatiales
- Réseaux sécurisés par les pouvoirs publics
- Installations sous contrôle aérien
- Systèmes de fabrication isolés
