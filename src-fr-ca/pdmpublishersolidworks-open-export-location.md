# Ouvrir l'emplacement d'exportation à l'achèvement

Activez **Open Export Location On Completion** pour ouvrir le dossier de sortie principal après un travail de publication réussi.

![Ouvrir l'emplacement d'exportation à l'achèvement dans les paramètres Publier](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox2_Open_export_location_on_completion_Light_100.png)
Ce réglage est disponible dans **PDMPublisher for SOLIDWORKS**. Il est utile pour un workflow de publication interactif car les fichiers générés sont immédiatement disponibles pour examen.

> [!NOTE]
> Cette option ouvre la principale [Exportation] (pdmpublisher-options/export-location.md). Lorsque des emplacements spécifiques à une extension sont activés, d'autres formats peuvent avoir été écrits dans leurs dossiers de surcharge configurés.

Désactiver le réglage lors de la publication à un emplacement réseau qui ne devrait pas s'ouvrir automatiquement ou lorsque l'ouverture du dossier interrompreait le workflow SOLIDWORKS actuel.
