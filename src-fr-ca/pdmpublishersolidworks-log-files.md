# Enregistrer et effacer les journaux

Utilisez les commandes de la fenêtre **PDMPublisher > Logs** pour conserver un enregistrement de travail ou commencer par une liste de journaux vide.

![Copier, enregistrer, effacer et fermer les commandes dans la fenêtre des journaux d'édition](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/logs-errors-filter-20260908.png)
<a id="save-logs"></a>
## Enregistrer les journaux

1. Sélectionnez **Save...**.
2. Choisissez une destination et un nom de fichier.
3. Enregistrer sous forme de fichier `.log` ou `.txt`.

PDMPublisher suggère un nom de fichier contenant le nom du produit, le nom de l'ordinateur et l'identificateur de session de travail. Le fichier enregistré contient toutes les entrées courantes du journal, y compris les entrées cachées par le filtre de recherche.

Enregistrer le journal immédiatement après l'emploi que vous devez étudier afin que les entrées non liées des emplois ultérieurs ne soient pas mélangées dans le dossier de support.

<a id="clear-logs"></a>
## Effacer les journaux

Sélectionnez **Clear** pour supprimer les entrées courantes dans la mémoire. Utilisez **Copy selected** ou **Copy all** lorsque vous avez seulement besoin de coller des entrées dans un message au lieu de sauvegarder un fichier.

Effacer la fenêtre ne supprime pas les fichiers journaux qui ont déjà été enregistrés sur le disque. Sauvegardez tout ce dont vous avez besoin avant de sélectionner **Clear** car les entrées dans la mémoire ne peuvent pas être restaurées depuis la fenêtre.

> [!TIP]
> Inclure le journal enregistré et le nom du fichier source lors de la communication avec `support@bluebytesystemsinc.zohodesk.com`.
