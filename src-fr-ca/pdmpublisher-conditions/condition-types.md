# Types d'état

État Type contrôle comment PDMPublisher compare la variable sélectionnée à la valeur saisie.

![Sélection du type de condition dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Dropdown2_Light_100.png)
| Type | Utiliser lorsque |
|---|---|
| Texte égal/pas égal | La valeur doit correspondre ou non à un texte spécifique. |
| Le texte contient / ne contient pas | La valeur doit seulement inclure ou éviter une partie du texte. |
| Longueur du texte | La longueur du texte est importante. |
| Nombre de comparaisons | La valeur est un nombre. |
| Comparaison des dates | La valeur est une date. |
| Oui/Pas de comparaison | La valeur est une variable oui/non. |

Texte égal prend en charge `*` en tant que wildcard.
