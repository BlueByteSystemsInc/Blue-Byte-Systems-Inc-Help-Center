# Ajouter des conditions et des groupes

Utilisez les conditions pour inclure ou exclure les fichiers avant que PDMPublisher les exporte.

Les groupes de condition créés ici sont stockés dans le **PDMPublisher for SOLIDWORKS Publish profile** sélectionné.

![Conditions contrôle la page dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Default_Light_100.png)
Les groupes de condition peuvent utiliser ET ou OU logique. Les groupes imbriqués vous permettent d'élaborer des règles plus détaillées.

Utilisez le bouton groupe pour ajouter un autre groupe ET/OU. Utilisez le bouton condition pour ajouter une règle dans le groupe sélectionné.

Les conditions individuelles et les groupes peuvent être activés ou désactivés avec la case à gauche.
