# Champs d'état

Chaque condition compare une valeur de fichier à la règle que vous définissez.

![Ligne de condition dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Default_Light_100.png)
| Champ | Signification |
|---|---|
| Variable | Valeur variable ou intégrée à vérifier. |
| Type de condition | La règle de comparaison à appliquer. |
| Valeur | La valeur à comparer. |
| Configuration | Configuration pour lire la valeur de. Laissez vide pour utiliser la configuration SOLIDWORKS référencée ou active lorsque prise en charge. |

Les comparaisons textuelles ne sont pas sensibles aux cas.
