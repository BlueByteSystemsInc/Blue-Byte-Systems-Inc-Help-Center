# ERP Sync

Ouvrir **PDMPublisher > Settings > ERP Sync** sous **Integration**.

![Page ERP Sync dans PDMPublisher pour les paramètres SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_ERP_Sync_Default_Light_100.png)
ERP Sync est réservé à une intégration planifiée qui synchronisera les informations SOLIDWORKS et PDM avec les systèmes ERP. Le comportement de configuration est toujours en cours de définition et l'intégration n'est pas disponible dans la version actuelle.

> [!IMPORTANT]
> La présence de cette page n'autorise pas la ERP synchronisation. Ne construisez pas de workflow de production autour d'elle avant qu'une version annonce que ERP Sync est disponible.

Utilisez **Search Options** pour trouver la page en entrant `ERP` ou `integration`. **Reset**, **Import** et **Export** s'appliquent au système de paramètres, mais il n'y a pas encore d'options ERP Sync à enregistrer.
