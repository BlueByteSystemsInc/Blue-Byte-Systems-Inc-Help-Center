# Version et mises à jour

Utilisez le groupe **Updates** CommandManager ou ouvrez **PDMPublisher > Settings > Support and Updates** pour afficher la version installée et vérifier si une nouvelle version est disponible.

![Support et mises à jour page montrant les versions installées et disponibles](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Support_Updates_Default_Light_100.png)
- **Installed version** est la version chargée dans la session SOLIDWORKS actuelle.
- **Latest version** est la version rapportée par le service de mise à jour.
- **You are using the latest version** signifie que la version installée correspond à la version disponible.
- **A new version is available** identifie la nouvelle version.
- **Could not check for updates** signifie que la vérification de la version en ligne n'a pas pu être effectuée.

Sélectionnez **Check for updates** pour actualiser les informations de la version. Un aperçu installé ou une construction plus récente peut avoir une version plus élevée que la version actuellement rapportée par le service de mise à jour; lire les deux valeurs avec le message d'état.

<a id="download-an-update"></a>
## Télécharger une mise à jour

Lorsqu'une mise à jour est disponible, utilisez l'action de téléchargement affichée pour ouvrir le téléchargement de l'installateur dans votre navigateur.

Fermer SOLIDWORKS avant de lancer l'installation. Enregistrer les documents ouverts d'abord, et débloquer l'installateur téléchargé de ses propriétés de fichier Windows si nécessaire par votre environnement.

Pour les instructions d'installation, voir [Installer PDMPublisher pour SOLIDWORKS](pdmpublishersolidworks_installation.md).

La même page fournit également des liens **Support**, **Legal notices** et **License agreement**.
