<a id="installation-statistics"></a>
## Statistiques d'installation

Le paramètre **Share installation and license statistics** contrôle un rapport d'installation facultatif. Lorsqu'il est activé, PDMPublisher envoie au plus un rapport par jour pendant que SOLIDWORKS est en cours d'exécution.

Le rapport comprend un identifiant d'installation aléatoire, le dossier d'installation, les versions de PDMPublisher et de SOLIDWORKS, les versions PDM installées, l'édition, la version et l'architecture de Windows, le nom d'utilisateur et le domaine Windows, la société de la licence, le niveau de licence et sa date d'expiration lorsqu'elle est disponible. Le site Web utilise l'adresse IP de connexion pour estimer le pays, la province ou l'État et la ville. Il ne recueille pas les clés de licence, les mots de passe, les adresses courriel, le contenu des documents CAO ou les noms de fichiers des documents.

Décochez la case pour arrêter les rapports futurs. La préférence est enregistrée immédiatement pour l'utilisateur Windows actuel et n'est pas incluse dans les paramètres partagés. Un rapport déjà transmis ne peut pas être rappelé.
