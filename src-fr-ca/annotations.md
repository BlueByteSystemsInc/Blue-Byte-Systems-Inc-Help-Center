# Page de tâche des annotations

Utilisez la page des tâches Annotations pour ajouter des notes de texte ou des filigranes aux documents PDF exportés.

> [!IMPORTANT]
> Ceci est la page des annotations **tâche PDM**. Les commandes d'annotation sont également utilisées par le complément SOLIDWORKS, mais les variables PDM proviennent du contexte des tâches voûtées. Voir [Complément SOLIDWORKS Annotations](pdmpublishersolidworks_annotations.md).

![Éditeur d'annotations mis à jour de la tâche PDM](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/task-annotations-20261009.png)
Chaque annotation peut avoir son propre texte, formatage, position, règle de feuille, et état actif.

Le grand espace de travail affiche les annotations configurées pour la tâche. Faites glisser une annotation pour la placer, utilisez ses poignées pour la redimensionner ou double-cliquez pour modifier son texte. Les valeurs **X** et **Y** définissent une position de sortie exacte.

<a id="annotation-settings"></a>
## Paramètres d' annotation

| Réglage | Résumé | Détails |
|---|---|---|
| Ajouter l'annotation | Créez une nouvelle boîte d'annotation. | [Ouvrir](pdmpublisher-annotations/add-annotation.md) |
| Texte de l'annotation | Saisissez du texte fixe ou utilisez des variables PDM. | [Ouvrir](pdmpublisher-annotations/annotation-text.md) |
| Espaces réservés de requête SQL | Récupérer le texte d'annotation d'une base de données SQL en utilisant le nom de fichier, la partie, l'assemblage ou la valeur de dessin. | [Ouvrir](pdmpublisher-annotations/sql-query-placeholders.md) |
| Formatage du texte | Définir la police, la taille et le style texte. | [Ouvrir](pdmpublisher-annotations/text-formatting.md) |
| Filigrane | Rotation et décoloration d'une annotation pour une sortie de style filigrane. | [Ouvrir](pdmpublisher-annotations/watermark.md) |
| Activité | Inclure ou sauter une annotation sans la supprimer. | [Ouvrir](pdmpublisher-annotations/active.md) |
| Fonction | Déplacez l'annotation ou définissez des pourcentages X/Y. | [Ouvrir](pdmpublisher-annotations/position.md) |
| Feuilles | Choisissez les feuilles de dessin qui reçoivent l'annotation. | [Ouvrir](pdmpublisher-annotations/sheets.md) |
