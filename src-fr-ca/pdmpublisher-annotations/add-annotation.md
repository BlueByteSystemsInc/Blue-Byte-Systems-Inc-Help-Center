# Ajouter l'annotation

Utilisez le bouton Ajouter l'annotation pour créer une nouvelle boîte d'annotation.

Les annotations créées ici sont stockées dans le **PDMPublisher for SOLIDWORKS Publish profile** sélectionné.

![PDMPublisher pour l'éditeur d'annotation SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
De nouvelles annotations sont ajoutées à l'aperçu de la page et peuvent ensuite être éditées, positionnées, activées ou transformées en filigrane.

Utilisez une annotation pour chaque note séparée ou filigrane que vous souhaitez placer sur le PDF exporté.
