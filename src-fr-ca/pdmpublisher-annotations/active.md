# Activité

La case à cocher Active contrôle si une annotation est incluse dans le PDF exporté.

Dans PDMPublisher pour SOLIDWORKS, l'état est enregistré dans le profil Publier sélectionné.

![Commande active d'annotation dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
Les nouvelles annotations sont actives par défaut.

Éteignez Active lorsque vous voulez garder la configuration d'annotation mais sautez-la pendant la publication.
