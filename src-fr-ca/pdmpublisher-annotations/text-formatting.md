# Formatage du texte

Utilisez les contrôles de formatage pour modifier la façon dont l'annotation apparaît sur le PDF exporté.

![Formage du texte de l'annotation dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
Le formatage commun comprend:

- Police
- Taille du texte
- Poêle
- italique

Chaque annotation peut utiliser son propre formatage. L'annotation sélectionnée est surlignée pour que vous puissiez voir laquelle est en cours d'édition.
