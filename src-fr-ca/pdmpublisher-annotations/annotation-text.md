# Texte de l'annotation

Entrez le texte qui doit apparaître sur le PDF exporté.

![Mesures du texte de l'annotation dans PDMPublisher pour SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Dropdown1_Light_100.png)
Le texte de l'annotation peut être des valeurs de texte fixe ou de propriété dynamique.

Le menu valeur inclut les propriétés personnalisées de SOLIDWORKS et les valeurs prises en charge à partir du document actif.

Utilisez des valeurs dynamiques lorsque l'annotation doit inclure des informations telles que le numéro de pièce, la révision, le projet, le client, l'état ou d'autres métadonnées de document disponibles pour le produit actuel.

Pour récupérer le texte d'annotation d'une base de données SQL, consultez [SQL Query Placeholders](sql-query-placeholders.md).
