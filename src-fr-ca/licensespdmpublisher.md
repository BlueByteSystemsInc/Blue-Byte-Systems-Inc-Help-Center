# Informations sur la licence

<a id="pdmpublisher-for-solidworks"></a>
## PDMPublisher pour SOLIDWORKS

Ouvrez **PDMPublisher > License Key**, ou ouvrez **PDMPublisher > Settings > License Key**.

![PDMPublisher pour la page clé de la licence SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/license-community-20260908.png)
| Contrôle | Ce qu'il fait |
| --- | --- |
| **Company name** | Indique la société associée à la licence. |
| **License key** | Accepte la clé fournie avec la commande ou l'essai. |
| Bouton oculaire | Affiche ou masque temporairement la clé de licence saisie. |
| **Activate** | Active la licence saisie sur cet ordinateur. |
| **Deactivate** | Lance une licence active depuis cet ordinateur. Il est indisponible jusqu'à ce qu'une licence soit active. |
| **Buy license(s)** | Ouvre la page d'achat PDMPublisher. |
| **Request New Trial** | Ouvre la page de demande de licence d'essai. |

<a id="activate-a-solidworks-license"></a>
### Activer une licence SOLIDWORKS

1. Entrez le **Company name** exactement comme fourni avec la licence.
2. Collez le **License key**.
3. Sélectionnez **Activate**.
4. Confirmez que la zone d'état signale une licence active.

Sélectionnez **Deactivate** avant de déplacer une licence vers un autre ordinateur, de remplacer l'ordinateur ou de faire un changement de système qui pourrait affecter l'identité de la machine.

<a id="community-edition"></a>
### Publication communautaire

Sans licence de paiement ou d'essai activée, la page identifie les limites de l'édition communautaire:

- Sortie PDF, DXF et STEP uniquement.
- Jusqu'à cinq références par course.
- Les paramètres Premium, y compris les emplacements d'exportation par format de fichier, ne sont pas disponibles.

Utilisez **Request New Trial** pour évaluer les fonctionnalités premium, ou consultez [Obtenez un essai de 7 jours] (pdmpublishertrial.md).

<a id="pdmpublisher-for-pdm-professional"></a>
## PDMPublisher pour PDM Professional

<a id="managing-a-license"></a>
### Gestion d'une licence

Votre licence est faite d'un **secret key** qui vous a été fourni dans le *order email*.

Votre licence vous permet d'utiliser PDM Publisher :

- Pour une durée spécifiée.
- Un certain nombre de domaines (nombre du coffre-forts où vous pouvez installer le complément).

Pour gérer votre licence :

- Connectez-vous à votre coffre depuis l'outil Administration PDM.
- *Clic droit* le complément du noeud **Add-ins** et *sélectionner* ***Manage license...***

<p align="center">
<img src="https://pdmpublisher.com/help/images/pdmpublisher_license_manager.png" alt="PDMPublisher license manager dialog" width="800">
</p>

<a id="activating-a-pdm-professional-license"></a>
### Activer une licence PDM Professional

Pour activer une licence :
- *Entrez* votre clé de licence et *cliquez* sur ***Activate*** pour utiliser la licence de l’**[étape précédente](#managing-a-license)**.

<a id="deactivating-a-pdm-professional-license"></a>
### Désactivation d'une licence PDM Professional

Pour désactiver une licence :
- *Cliquez sur * ***Deactivate*** dans le gestionnaire de licence pour arrêter d'utiliser la licence sur le coffre-fort connecté.

<a id="reactivate-a-pdm-professional-license"></a>
### Réactiver une licence PDM Professional

Pour réactiver la licence, veuillez suivre ces instructions :

1. *Ouvrir* l'outil d'administration PDM.
2. *Expand* les nœuds supplémentaires et *droit-clic* sur PDMPublisher.
3. *Cliquez sur * ***Manage license…***
4. *Entrez votre clé de licence. Si vous réactivez la même clé de licence après expiration, vous n'avez pas besoin de réentrer la clé de licence.
5. Cliquez sur **Activate**.
6. Votre nouvelle date d'expiration devrait apparaître.
