# Publisher Macros

Ouvrir **PDMPublisher > Settings > Publisher Macros** sous **Integration**.

![Page Publisher Macros dans PDMPublisher pour les paramètres SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publisher_Macros_Default_Light_100.png)
Publisher Macros est réservé pour une intégration planifiée qui va programmer des travaux PDMPublisher pour fonctionner automatiquement. Le comportement de configuration est toujours en cours de définition et l'intégration n'est pas disponible dans la version actuelle.

> [!IMPORTANT]
> Publisher Macros est séparé de l'option **Run macro after saving** dans [Save As New](pdmpublishersolidworks_save-as-new.md). Save As New peut exécuter une macro SOLIDWORKS existante après avoir créé une copie; Publisher Macros est l'intégration de programmation prévue.
