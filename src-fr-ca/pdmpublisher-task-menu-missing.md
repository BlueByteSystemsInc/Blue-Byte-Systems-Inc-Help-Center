# Pourquoi le menu Tâches manque-t-il ?

Si le menu **Tasks** n'apparaît pas dans l'Explorateur de fichiers, les paramètres de l'utilisateur PDM peuvent cacher add-ins.

Ouvrez l'outil d'administration de SOLIDWORKS PDM, ouvrez la boîte de dialogue des paramètres de l'utilisateur et confirmez que add-ins est visible pour cet utilisateur.

<p align="center">
<img src="https://pdmpublisher.com/help/images/adminsettings.png" alt="PDM Administration user settings" width="800">
</p>

Après que add-ins soient visibles, rouvrez File Explorer et faites un clic droit sur un fichier dans le coffre. La tâche doit apparaître sous **Tasks**.
