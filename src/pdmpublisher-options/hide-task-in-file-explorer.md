# Hide Task in File Explorer

![Hide task in file explorer setting](/images/pdmpublisher/screenshots/options-018-property-hide-task-in-file-explorer.png)

Hides the task command from the PDM File Explorer right-click menu.

By default, the task is shown in File Explorer under `Tasks > TaskName`.

Use this for task configurations that should be run only from controlled workflows or administration contexts.
