# Delete Duplicates Outside the Destination Folder

![Delete duplicates setting](/images/pdmpublisher/screenshots/options-011-property-delete-duplicates-outside-the-destination-folder.png)

Removes duplicate output files outside the destination folder.

Use this when the task should keep one canonical exported file location.

> [!WARNING]
> Review this setting before using it in vaults where older exported deliverables must be retained for audit or release history.
