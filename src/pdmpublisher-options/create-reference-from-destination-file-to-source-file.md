# Create Reference from Destination File to Source File

![Create reference setting](/images/pdmpublisher/screenshots/options-010-property-create-reference-from-dest-file-to-source-file.png)

Creates a PDM reference from the exported destination file back to the source file.

This helps users trace an exported deliverable back to the model or drawing that created it.
