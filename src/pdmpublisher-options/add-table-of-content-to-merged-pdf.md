# Add Table of Content to Merged PDF

![Add table of content setting in PDMPublisher for SOLIDWORKS](/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox10_Add_table_of_content_to_merged_PDF_Light_100.png)

Adds a generated table of contents page to the merged PDF.

> [!NOTE]
> This setting is available in both the **PDM task** and **SOLIDWORKS add-in** and depends on merged assembly PDF output.

![Customize TOC columns dialog](/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_TOC_columns_Default_Light_100.png)

Use this with [Merge Exported PDFs into One Master PDF](merge-exported-pdfs.md). The table of content is created for the merged PDF, not for separate PDF files.

Related settings:

- [Merge Exported PDFs into One Master PDF](merge-exported-pdfs.md) creates the master PDF that receives the table of content.
- [Export References to File Formats Individually](export-references-individually.md) is required when merging PDFs from an assembly.
- [File Formats](file-formats.md) must include `PDF`.
- [PDF Bookmarks](pdf-bookmarks.md) can add navigation inside the merged PDF.
- [Table Columns](table-columns.md) controls the columns used in generated PDF tables.
