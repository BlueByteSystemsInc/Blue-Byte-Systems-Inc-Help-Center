# Use This Version of SOLIDWORKS

![Use this version of SOLIDWORKS setting](/images/pdmpublisher/screenshots/options-034-property-use-this-version-of-solidworks.png)

Selects which installed SOLIDWORKS version should run the publish job.

![SOLIDWORKS version dropdown](/images/pdmpublisher/screenshots/options-dropdown-005-use-this-version-of-solidworks.png)

The SOLIDWORKS icon is a visual identifier. Select a year installed on the task host, or select `Latest` to use the newest supported installation detected on that computer.
