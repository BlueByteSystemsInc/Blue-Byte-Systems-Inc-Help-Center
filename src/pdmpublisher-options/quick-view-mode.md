# Quick View Mode (Drawings Only)

![Quick view mode setting](/images/pdmpublisher/screenshots/options-024-property-quick-view-mode-(drawings-only).png)

Opens drawings in quick view mode where supported. This can reduce load time for drawing-only export operations.

> [!WARNING]
> Quick view mode uses the cached drawing view. It may not use the latest referenced model data.

Use this only for extremely large drawings where normal drawing loading is too slow.
