# Calculation Method

![Calculation method setting](/images/pdmpublisher/screenshots/options-008-property-calculation-method.png)

Controls how references are calculated for BOM and quantity evaluation.

![Calculation method dropdown](/images/pdmpublisher/screenshots/options-dropdown-003-calculation-method.png)

This setting is related to [Template](template.md), because the selected BOM template supplies the reference and quantity information PDMPublisher evaluates.

- **As built** uses references as they were when the assembly was checked in.
- **Latest** uses the latest references available in PDM.
