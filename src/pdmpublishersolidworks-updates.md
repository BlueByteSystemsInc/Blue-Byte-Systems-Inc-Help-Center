# Version and Updates

The About tab displays the installed version and checks whether a newer release is available.

- **Current Version** is the version installed in the current SOLIDWORKS session.
- **You are using the latest version** means the installed version matches the available release.
- **A new version is available** identifies the newer release.
- **Could not check for updates** means the online version check could not be completed.

The current documented release is `2026.08.10`.

## Download an Update

Select **Download the latest version...** to open the installer download in your browser.

Close SOLIDWORKS before running the installer. Save open documents first, and unblock the downloaded installer from its Windows file properties if required by your environment.

For installation guidance, see [Installing or Updating PDM Add-ins](installingpdmaddins.md).
