# Annotation Text

Double-click a note to edit its text. Use the dropdown beside the editor to insert a property placeholder. Literal text and placeholders can be combined.

The SOLIDWORKS add-in offers custom properties from loaded drawings and referenced models. The PDM task offers vault variables and [SQL placeholders](sql-query-placeholders.md). Values are resolved during publishing.

For a QR code, the evaluated note text becomes the encoded content. Double-click the QR preview to edit the original text.
