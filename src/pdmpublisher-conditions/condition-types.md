# Condition Types

Condition Type controls how PDMPublisher compares the selected variable to the entered value.

![Condition type dropdown](/images/pdmpublisher/screenshots/conditions-(2)-dropdown-001-condition-type-values.png)

| Type | Use when |
|---|---|
| Text equal / not equal | The value must match or not match specific text. |
| Text contains / does not contain | The value only needs to include or avoid part of the text. |
| Text length | The text length matters. |
| Number comparisons | The value is a number. |
| Date comparisons | The value is a date. |
| Yes/No comparisons | The value is a yes/no variable. |

Text equal supports `*` as a wildcard.
