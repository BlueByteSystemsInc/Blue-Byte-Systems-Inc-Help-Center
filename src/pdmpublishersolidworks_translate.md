# Translate

Open **PDMPublisher > Settings > Translate** under **Utilities**.

![Translate page in PDMPublisher for SOLIDWORKS settings](/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Translate_Default_Light_100.png)

Translate is reserved for a planned workflow for translating properties, feature names, and other SOLIDWORKS document text. Translation behavior and settings are still being defined, and the command is not available in the current release.

The disabled **Translate** CommandManager command and this settings page indicate the planned location of the feature. They do not perform translation yet.
