# Publisher Macros

Open **PDMPublisher > Settings > Publisher Macros** under **Integration**.

![Publisher Macros page in PDMPublisher for SOLIDWORKS settings](/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publisher_Macros_Default_Light_100.png)

Publisher Macros is reserved for a planned integration that will schedule PDMPublisher jobs to run automatically. Configuration behavior is still being defined and the integration is not available in the current release.

> [!IMPORTANT]
> Publisher Macros is separate from the **Run macro after saving** option in [Save As New](pdmpublishersolidworks_save-as-new.md). Save As New can run an existing SOLIDWORKS macro after it creates a copy; Publisher Macros is the planned scheduling integration.
