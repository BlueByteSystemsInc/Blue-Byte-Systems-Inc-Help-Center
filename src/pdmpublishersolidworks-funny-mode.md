# Funny Mode

Enable **Enable funny mode** on the About tab to use alternate progress messages while a publish job runs.

Funny Mode changes message wording only. It does not change:

- Files selected for processing
- Conditions or quantities
- Output formats or locations
- Export performance or results

Disable the option when standard progress wording is preferred. The setting applies to later publish jobs.
