# Update the PDMPublisher PDM Task

Update the add-in in your vault using [PDMDeploy](updateaddinswithcdpdm.md) or import the supplied [CEX file](installingpdmaddins.md) in PDM Administration.

1. Finish running publishing tasks and save any task setup changes.
2. Sign in to the vault with an account permitted to update add-ins.
3. Install the package using PDMDeploy, or import the CEX file and confirm replacement of the existing PDMPublisher add-in.
4. Follow any PDM restart prompts, then check the version under the vault's Add-ins node.
5. Review your existing task settings before running a test publish.

For installation errors, record the full PDM error message and contact [support](https://support.bluebyte.biz).
