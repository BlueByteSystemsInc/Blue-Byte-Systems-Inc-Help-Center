# ERP Sync

Open **PDMPublisher > Settings > ERP Sync** under **Integration**.

![ERP Sync page in PDMPublisher for SOLIDWORKS settings](/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_ERP_Sync_Default_Light_100.png)

ERP Sync is reserved for a planned integration that will synchronize SOLIDWORKS and PDM information with ERP systems. Configuration behavior is still being defined and the integration is not available in the current release.

> [!IMPORTANT]
> The presence of this page does not enable ERP synchronization. Do not build a production workflow around it until a release announces that ERP Sync is available.

Use **Search Options** to find the page by entering `ERP` or `integration`. **Reset**, **Import**, and **Export** apply to the settings system, but there are no ERP Sync options to save yet.
