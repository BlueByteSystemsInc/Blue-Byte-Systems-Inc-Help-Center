# Community vs Premium Comparison

PDMPublisher for SOLIDWORKS runs as the **Community Edition** when no paid Premium license is active. Community includes the main workflows with format, row, and settings limits. Premium removes those limits and unlocks all licensed settings.

> [!IMPORTANT]
> This comparison applies only to the **SOLIDWORKS add-in**. The [PDMPublisher PDM Task](pdmpublisher.md) is a separate product with separate licensing.

## Feature Comparison

| Feature | Community Edition | Premium Edition |
| --- | --- | --- |
| License | No paid Premium license required | Activated paid Premium license |
| Publish formats | PDF, DXF, and STEP only | All supported publish formats |
| References per publishing run | Up to 5 | No Community Edition reference limit |
| Save As New | Saves filename settings; choose the destination for each save | Saves reusable filename and destination settings |
| Clone Tree | Processes up to 5 rows per run | No Community Edition row limit |
| Property Doctor | Applies changes to up to 5 rows at a time | No Community Edition row limit |
| BOM Manager | Displays and exports up to 10 rows | No Community Edition row limit |
| ERP Sync | Reviews and synchronizes up to 10 rows | No Community Edition row limit |
| Export locations by file format | Not available | Available |
| Profiles and settings transfer | Available | Available |
| Annotations, conditions, and logs | Available | Available |
| PDM-backed values and locations | Available when a local vault view and permissions allow access | Available when a local vault view and permissions allow access |

Community limits apply to each operation; they do not expire after a fixed number of uses. Premium does not change SOLIDWORKS or PDM permissions.

## Licensing

Open **PDMPublisher > License Key** to view the active edition, activate a Premium key, or deactivate a license before moving it to another computer.
