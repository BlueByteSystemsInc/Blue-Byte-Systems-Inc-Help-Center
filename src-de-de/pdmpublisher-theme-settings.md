# Themeneinstellungen

PDMPublisher kann dem aktuellen Windows-App-Thema folgen. Wenn die Theme-Synchronisation aktiviert ist, verwenden die PDMPublisher-Task-Setup-Seiten helle oder dunkle Farben, um Windows zu entsprechen.

![PDMPublisher Options page using the Windows dark theme](https://pdmpublisher.com/help/images/pdmpublisher/dark-theme-options.png)

Theme Synchronisation ändert nur Farben. Es ändert nicht das Design, den Standort oder das Verhalten der Aufgabeneinstellungen.

> [!NOTE]
> Theme Synchronisation ist standardmäßig ausgeschaltet. Wenn es ausgeschaltet ist, behält PDMPublisher seine ursprünglichen Lichtfarben bei und ignoriert Windows-Themenänderungen.

<a id="turn-theme-synchronization-on-or-off"></a>
## Theme Synchronisation ein- oder ausschalten

1. Öffnen Sie das SOLIDWORKS PDM Administration Tool.
2. Erweitern Sie **Add-ins** und klicken Sie mit der rechten Maustaste auf **PDMPublisher**.
3. Wählen Sie **Theme settings...**.

![Befehl Theme-Einstellungen im PDMPublisher-Add-in-Menü](https://pdmpublisher.com/help/images/pdmpublisher/theme-settings-menu.png)
Der Bestätigungsdialog zeigt:

- Das aktuelle Windows-Thema: **Light** oder **Dark**.
- Ob PDMPublisher Theme Synchronisation ist derzeit **On** oder **Off**.
- Die Änderung, die vorgenommen wird, wenn Sie **Yes** auswählen.

![Theme Synchronisation Bestätigungsdialog](https://pdmpublisher.com/help/images/pdmpublisher/theme-settings-confirmation.png)
Wählen Sie **Yes**, um die Einstellung zu ändern, oder **No**, um sie unverändert zu lassen.

- Durch Drehen der Synchronisation **on** folgt PDMPublisher dem aktuellen Windows-Thema und zukünftigen Windows-Themaänderungen.
- Die Synchronisation **off** gibt PDMPublisher in die ursprünglichen Lichtfarben zurück und ignoriert zukünftige Windows-Themenänderungen.

> [!TIP]
> Schließen und öffnen Sie eine Task-Setup-Seite, die bereits geöffnet war, wenn alle Steuerelemente nicht sofort nach dem Ändern dieser Einstellung aktualisiert werden.
