# Betroffenes Ausfuhrdokument

![Aktive Dokumenteneinstellung exportieren](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-012-property-export-affected-document.png)
Exportiert das betroffene Dokument, das die Top-Level-Datei ist, die die PDM-Task ausgelöst hat.

Deaktivieren Sie dies nur, wenn die Aufgabe referenzierte Dokumente verarbeiten soll, nicht jedoch das Dokument auf oberster Ebene.
