# Vault Activity Logs

![Einstellung der Vault Activity Logs](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-035-property-vault-activity-logs.png)
Erstellt detaillierte Task-Logs, die die steps zeigen, die während der Veröffentlichung durchgeführt wurden.

Aktivieren Sie dies, wenn Sie eine neue Aufgabenkonfiguration validieren oder das Exportverhalten beheben.

Verwenden Sie [Server-Synced Activity Logs](server-synced-activity-logs.md) nur, wenn diese Aktivitätsprotokolle auch für die Support-Überprüfung verfügbar sein sollten.

Verwenden Sie [Log Ordner (Vault Only)](log-folder-vault-only.md), wenn Aktivitätsprotokolle in einen bestimmten Vault-Ordner geschrieben werden sollen.
