# Ignorieren Sie Unterbaugruppen Kinder, wenn Zustandsprüfungen fehlschlagen

![Unterbaugruppen-Kindereinstellung in PDMPublisher für SOLIDWORKS ignorieren](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox4_Ignore_sub-assembly_children_when_condition_checks_fail_Light_100.png)
Wenn Bedingungen eine Unterbaugruppe ablehnen, verhindert diese Option, dass die Kinder der Unterbaugruppe bearbeitet werden.

> [!NOTE]
> Diese Einstellung ist sowohl im **PDM task** als auch im **SOLIDWORKS add-in** verfügbar. Es beeinflusst die Assemblerreferenzverarbeitung und hat keine Auswirkungen auf ein eigenständiges Teil oder eine Zeichnung.

> [!WARNING]
> Wenn eine abgelehnte Unterbaugruppe Kinder enthält, die noch unabhängig exportiert werden sollten, lassen Sie diese Option aus.
