# Erstellen Sie eine Referenz von der Zieldatei zur Quelldatei

![Referenzeinstellung erstellen](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-010-property-create-reference-from-dest-file-to-source-file.png)
Erstellt eine PDM-Referenz aus der exportierten Zieldatei zurück in die Quelldatei.

Dies hilft Benutzern, eine exportierte Lieferung zurück zu dem Modell oder der Zeichnung zu verfolgen, die sie erstellt hat.
