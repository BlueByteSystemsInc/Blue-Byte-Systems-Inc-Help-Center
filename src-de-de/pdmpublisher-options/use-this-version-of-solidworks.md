# Verwenden Sie diese Version von SOLIDWORKS

![Verwenden Sie diese Version der Einstellung SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-034-property-use-this-version-of-solidworks.png)
Wählen Sie aus, welche SOLIDWORKS-Version installiert wurde, um den Veröffentlichungsauftrag auszuführen.

![SOLIDWORKS Version Dropdownliste](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-dropdown-005-use-this-version-of-solidworks.png)
Das SOLIDWORKS-Symbol ist eine visuelle Kennung. Wählen Sie ein Jahr aus, das auf dem Task-Host installiert ist, oder wählen Sie `Latest`, um die neueste unterstützte Installation zu verwenden, die auf diesem Computer erkannt wurde.
