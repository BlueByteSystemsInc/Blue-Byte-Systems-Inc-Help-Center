# Kartenvariablen zwischen Quell- und Zieldatei

![Einstellung von Kartenvariablen](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-021-property-map-variables-between-source-and-destination-file.png)
Bildet Variablen aus der Quelldatei der generierten Zieldatei zu.

Verwenden Sie dies, wenn exportierte PDFs oder neutrale Dateien Metadaten für die Suche, Genehmigung oder nachgelagerte Automatisierung benötigen.

![Variabler Mapping-Dialog](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-dialog-variable-mapping.png)
Verwenden Sie **Add Mapping**, um eine neue Regel für Source-to-Destination-Variablen hinzuzufügen.

Spalten:

- **Source** ist die Variable aus der ursprünglichen Datei.
- **Value** zeigt den Wert, den PDMPublisher aus der Quelldatei liest.
- **Destination** ist die Variable, die in die exportierte Datei geschrieben wird.

`Source Revision Number` kann beispielsweise `Revision` zugeordnet werden, so dass die exportierte Datei den Revisionswert aus der Quelldatei behält.
