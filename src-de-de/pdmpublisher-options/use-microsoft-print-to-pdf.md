# Verwenden Sie Microsoft Print To PDF, um PDFs zu speichern

![Verwenden Sie Microsoft Print To PDF Einstellung](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-032-property-use-microsoft-print-to-pdf-to-save-pdfs.png)
Verwendet den Druckerpfad Windows **Microsoft Print to PDF** beim Erstellen von PDFs.

Verwenden Sie dies nur, wenn der normale Exportpfad PDF nicht Ihren Umgebungs- oder Ausgabeanforderungen entspricht.
