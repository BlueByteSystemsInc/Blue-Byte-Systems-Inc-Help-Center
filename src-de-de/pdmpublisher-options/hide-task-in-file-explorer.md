# Hide Task im Datei-Explorer

![Aufgabe in Datei-Explorer-Einstellung ausblenden](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-018-property-hide-task-in-file-explorer.png)
Versteckt den Task-Befehl aus dem PDM File Explorer Rechtsklick-Menü.

Standardmäßig wird die Aufgabe im File Explorer unter `Tasks > TaskName` angezeigt.

Verwenden Sie dies für Aufgabenkonfigurationen, die nur aus kontrollierten Workflows oder Verwaltungskontexten ausgeführt werden sollen.
