# Quick View Mode (nur Zeichnungen)

![Quick view mode setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-024-property-quick-view-mode-(drawings-only).png

Öffnet Zeichnungen im Schnellansichtsmodus, sofern unterstützt. Dies kann die Ladezeit für reine Exportvorgänge reduzieren.

> [!WARNING]
> Der Quick View-Modus verwendet die zwischengespeicherte Zeichnungsansicht. Es können nicht die neuesten referenzierten Modelldaten verwendet werden.

Verwenden Sie dies nur für extrem große Zeichnungen, bei denen die normale Zeichnungsbelastung zu langsam ist.
