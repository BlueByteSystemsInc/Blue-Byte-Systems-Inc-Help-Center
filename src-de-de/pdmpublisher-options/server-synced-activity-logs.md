# Server-Synced Activity Logs

![Server synchronisierte Aktivitätsprotokolle](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-025-property-server-synced-activity-logs.png)
Sendet Aktivitätsprotokolle an den Server, damit sie später auf Unterstützung und Fehlersuche überprüft werden können.

Diese Einstellung bezieht sich auf [Vault Activity Logs](turn-on-activity-tracking.md). Aktivieren Sie zuerst die Protokolle der Vault-Aktivität, damit die Aufgabe Protokolle senden kann.

> [!WARNING]
> Bestätigen Sie die Richtlinien Ihres Unternehmens, bevor Sie serversynchronisierte Protokolle aktivieren, wenn Dateinamen, Pfade, Variablennamen oder Jobhistorie als sensibel gelten.
