# Blätter

Verwenden Sie Blätter, um zu steuern, welche Zeichenseiten die Anmerkung erhalten.

![Annotationsblattauswahl in PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Dropdown3_Light_100.png)
Jede Anmerkung hat ihre eigene Blatteinstellung. Auf diese Weise können Sie eine Anmerkung auf jedem Blatt und eine weitere Anmerkung nur auf bestimmten Blättern platzieren.

Verwenden Sie dies, wenn Deckblätter, Detailblätter oder Herstellungsblätter unterschiedliche Notizen benötigen.
