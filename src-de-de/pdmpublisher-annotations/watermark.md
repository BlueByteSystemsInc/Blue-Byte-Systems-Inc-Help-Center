# Wasserzeichen

Aktivieren Sie Wasserzeichen, wenn die Anmerkung als Wasserzeichen auf dem exportierten PDF erscheinen soll.

![Wassermarkkontrolle in PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
Wenn Watermark aktiviert ist, dreht PDMPublisher die Anmerkung und macht sie halbtransparent, so dass sie den Zeichnungsinhalt nicht so stark abdeckt wie normaler Text.

Verwenden Sie dies für Labels wie Review-Kopien, vorläufige Dokumente, interne Verwendung oder Release-Status.
