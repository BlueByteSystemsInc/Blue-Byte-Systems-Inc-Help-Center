# Aktiv

Das Kontrollkästchen Aktiv steuert, ob eine Annotation im exportierten PDF enthalten ist.

In PDMPublisher für SOLIDWORKS wird der Zustand im ausgewählten Publish-Profil gespeichert.

![Aktive Annotationssteuerung in PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
Neue Anmerkungen sind standardmäßig aktiv.

Aktiv ausschalten, wenn Sie das Annotations-Setup beibehalten möchten, aber beim Veröffentlichen überspringen.
