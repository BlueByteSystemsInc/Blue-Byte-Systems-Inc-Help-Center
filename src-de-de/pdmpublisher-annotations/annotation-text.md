# Anmerkungen Text

Geben Sie den Text ein, der auf dem exportierten PDF erscheinen soll.

![Annotationstextsteuerelemente in PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Dropdown1_Light_100.png)
Annotationstext kann Fixtext oder dynamische Eigenschaftswerte sein.

Das Wertemenü enthält SOLIDWORKS benutzerdefinierte Eigenschaften und unterstützte Werte aus dem aktiven Dokument.

Verwenden Sie dynamische Werte, wenn die Anmerkung Informationen wie Teilenummer, Revision, Projekt, Kunde, Status oder andere für das aktuelle Produkt verfügbare Dokumentmetadaten enthalten soll.

Zum Abrufen von Anmerkungstext aus einer SQL-Datenbank siehe [SQL Query Placeholders](sql-query-placeholders.md).
