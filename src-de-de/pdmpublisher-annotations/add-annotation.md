# Annotation hinzufügen

Verwenden Sie die Schaltfläche Anmerkung hinzufügen, um ein neues Anmerkungsfeld zu erstellen.

Hier erstellte Annotationen werden im ausgewählten **PDMPublisher for SOLIDWORKS Publish profile** gespeichert.

![PDMPublisher für SOLIDWORKS Annotation Editor](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
Neue Anmerkungen werden der Seitenvorschau hinzugefügt und können dann bearbeitet, positioniert, aktiviert oder in ein Wasserzeichen geändert werden.

Verwenden Sie eine Anmerkung für jede separate Notiz oder jedes Wasserzeichen, das Sie auf dem exportierten PDF platzieren möchten.
