# Textformatierung

Verwenden Sie Formatierungssteuerelemente, um zu ändern, wie die Annotation auf dem exportierten PDF erscheint.

![Annotation text formatting in PDMPublisher for SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
Die gemeinsame Formatierung umfasst:

- Schriftzug
- Textgröße
- Fett
- Italisch

Jede Anmerkung kann ihre eigene Formatierung verwenden. Die ausgewählte Anmerkung wird hervorgehoben, damit Sie sehen können, welche bearbeitet wird.
