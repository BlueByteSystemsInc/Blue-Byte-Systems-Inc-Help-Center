# Anmerkungsposition

Anmerkungen können manuell oder durch X/Y-Werte positioniert werden.

![Annotationspositionskontrollen in PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
Sie können die Anmerkung ziehen, um sie visuell auf der Seite zu platzieren.

Sie können auch X- und Y-Koordinaten eingeben:

- X ist ein Prozentsatz der Blattbreite.
- Y ist ein Prozentsatz der Blatthöhe.

Verwenden Sie Koordinaten, wenn die Annotation jedes Mal an der gleichen Stelle landen muss.
