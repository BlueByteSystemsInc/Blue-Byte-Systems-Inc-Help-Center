# Bedingungen und Gruppen hinzufügen

Verwenden Sie Bedingungen, um Dateien einzuschließen oder auszuschließen, bevor PDMPublisher sie exportiert.

Hier erstellte Zustandsgruppen werden in der ausgewählten **PDMPublisher for SOLIDWORKS Publish profile** gespeichert.

![Bedingungen Seite steuert in PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Default_Light_100.png)
Bedingungsgruppen können UND oder ODER Logik verwenden. Mit verschachtelten Gruppen können Sie detailliertere Regeln erstellen.

Verwenden Sie die Gruppenschaltfläche, um eine weitere UND/ODER-Gruppe hinzuzufügen. Verwenden Sie die Schaltfläche Bedingung, um eine Regel innerhalb der ausgewählten Gruppe hinzuzufügen.

Einzelne Bedingungen und Gruppen können mit dem Kontrollkästchen links aktiviert oder deaktiviert werden.
