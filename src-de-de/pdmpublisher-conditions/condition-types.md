# Zustandsarten

Zustand Typ steuert, wie PDMPublisher die ausgewählte Variable mit dem eingegebenen Wert vergleicht.

![Zustandstypauswahl in PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Dropdown2_Light_100.png)
| Typ | Verwendung bei |
|---|---|
| Text gleich / nicht gleich | Der Wert muss mit einem bestimmten Text übereinstimmen oder nicht. |
| Text enthält / enthält nicht | Der Wert muss nur einen Teil des Textes enthalten oder vermeiden. |
| Textlänge | Die Länge des Textes ist wichtig. |
| Anzahlvergleiche | Der Wert ist eine Zahl. |
| Datumsvergleiche | Der Wert ist ein Datum. |
| Ja/Nein Vergleiche | Der Wert ist eine Ja/Nein-Variable. |

Text Equal unterstützt `*` als Platzhalter.
