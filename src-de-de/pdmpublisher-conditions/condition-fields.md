# Zustandsfelder

Jede Bedingung vergleicht einen Dateiwert mit der von Ihnen definierten Regel.

![Zustandszeile in PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Default_Light_100.png)
| Feld | Bedeutung |
|---|---|
| Variabel | Variable oder eingebauter Wert zu überprüfen. |
| Zustandsart | Die anzuwendende Vergleichsregel. |
| Wert | Der Wert zum Vergleichen. |
| Konfiguration | Konfiguration zum Lesen des Werts aus. Lassen Sie es leer, um die referenzierte oder aktive SOLIDWORKS-Konfiguration zu verwenden, wo sie unterstützt wird. |

Textvergleiche sind nicht fallsensibel.
