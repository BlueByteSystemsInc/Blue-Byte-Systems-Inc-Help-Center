# Version und Updates

Verwenden Sie die Gruppe **Updates** CommandManager oder öffnen Sie **PDMPublisher > Settings > Support and Updates**, um die installierte Version anzuzeigen und zu prüfen, ob ein neueres Release verfügbar ist.

![Seite Support und Updates mit installierten und verfügbaren Versionen](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Support_Updates_Default_Light_100.png)
- **Installed version** ist die Version, die in der aktuellen SOLIDWORKS-Sitzung geladen wurde.
- **Latest version** ist die vom Updatedienst gemeldete Version.
- **You are using the latest version** bedeutet, dass die installierte Version mit der verfügbaren Version übereinstimmt.
- **A new version is available** identifiziert das neuere Release.
- **Could not check for updates** bedeutet, dass die Online-Versionsprüfung nicht abgeschlossen werden konnte.

Wählen Sie **Check for updates**, um die Versionsinformationen zu aktualisieren. Eine installierte Vorschau oder ein neuerer Build kann eine höhere Version haben als die Version, die derzeit vom Updatedienst gemeldet wird; lesen Sie beide Werte zusammen mit der Statusmeldung.

<a id="download-an-update"></a>
## Download eines Updates

Wenn ein Update verfügbar ist, verwenden Sie die angezeigte Download-Aktion, um den Download des Installationsprogramms in Ihrem Browser zu öffnen.

Schließen Sie SOLIDWORKS, bevor Sie das Installationsprogramm ausführen. Speichern Sie zuerst geöffnete Dokumente und entsperren Sie das heruntergeladene Installationsprogramm von seinen Windows-Dateieigenschaften, wenn dies von Ihrer Umgebung erforderlich ist.

Zur Installationsanleitung siehe [PDMPublisher für SOLIDWORKS installieren](pdmpublishersolidworks_installation.md).

Die gleiche Seite bietet auch **Support**, **Legal notices** und **License agreement** Links.
