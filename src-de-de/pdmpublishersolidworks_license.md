# Lizenzverwaltung

Diese Seite gilt nur für **PDMPublisher for SOLIDWORKS**. PDM Task Lizenzverwaltung gehört zu den separaten [PDMPublisher für PDM Professional Dokumentation](licensespdmpublisher.md#pdmpublisher-for-pdm-professional).

Öffnen Sie **PDMPublisher > License Key** oder öffnen Sie **PDMPublisher > Settings > License Key**.

![Lizenzschlüsselseite für PDMPublisher für SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_License_Key_Default_Light_100.png)
| Kontrolle | Was es tut |
| --- | --- |
| **Company name** | Identifiziert das Unternehmen, das mit der Lizenz verbunden ist. Geben Sie es genau wie geliefert ein. |
| **License key** | Akzeptiert den mit der Bestellung gelieferten Schlüssel. |
| Augenknopf | Zeigt oder versteckt vorübergehend den eingegebenen Schlüssel. |
| **Activate** | Aktiviert den Schlüssel auf diesem Computer. |
| **Deactivate** | Gibt die aktive Lizenz frei, damit sie auf einen anderen Computer verschoben werden kann. |
| **Buy license(s)** | Öffnet die PDMPublisher für SOLIDWORKS Kaufseite. |

<a id="activate-a-license"></a>
## Eine Lizenz aktivieren

1. Geben Sie die gelieferten **Company name** und **License key** ein.
2. Wählen Sie **Activate**.
3. Bestätigen Sie, dass der Statusbereich eine aktive Lizenz meldet.

Deaktivieren Sie die Lizenz, bevor Sie den Computer ersetzen oder eine Systemänderung vornehmen, die die Maschinenidentität ändern kann.

Ohne kostenpflichtige Lizenz läuft PDMPublisher für SOLIDWORKS als Community Edition. Unter [Community oder Premium](pdmpublishersolidworks_comparison.md) finden Sie den vollständigen Funktions- und Limitvergleich. Die an anderer Stelle auf dieser Hilfeseite angebotene 7-Tage-Testversion gilt für den separaten **PDM Professional Task**, nicht für das SOLIDWORKS Add-in.
