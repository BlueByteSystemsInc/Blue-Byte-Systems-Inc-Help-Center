# ERP Sync

Öffnen Sie **PDMPublisher > Settings > ERP Sync** unter **Integration**.

![ERP Sync Seite in PDMPublisher für SOLIDWORKS Einstellungen](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_ERP_Sync_Default_Light_100.png)
ERP Sync ist für eine geplante Integration reserviert, die SOLIDWORKS und PDM-Informationen mit ERP-Systemen synchronisiert. Das Konfigurationsverhalten wird noch definiert und die Integration ist im aktuellen Release nicht verfügbar.

> [!IMPORTANT]
> Das Vorhandensein dieser Seite ermöglicht keine ERP synchronisierung. Bauen Sie keinen Produktionsworkflow um ihn herum, bis ein Release ankündigt, dass ERP Sync verfügbar ist.

Verwenden Sie **Search Options**, um die Seite zu finden, indem Sie `ERP` oder `integration` eingeben. **Reset**, **Import** und **Export** gelten für das Einstellungssystem, aber es gibt noch keine ERP Sync-Optionen zum Speichern.
