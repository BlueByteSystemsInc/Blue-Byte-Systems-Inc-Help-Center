# Offline-Lizenzaktivator

Das **PDMPublisher Offline License Activator** (activator.exe) ist ein sicheres, eigenständiges Konsolenprogramm, das für Umgebungen entwickelt wurde, in denen die Internetverbindung eingeschränkt oder verboten ist.

![offlineactivator](https://pdmpublisher.com/help/images/offlineactivator.png)
Mit diesem Tool können autorisierte Administratoren eine PDMPublisher-Lizenz nutzen, ohne:

- Internetzugang
- Cloud Validierung
- Externe HTTP-Kommunikation
- Telemetrie oder ausgehender Verkehr

Sie ist insbesondere bestimmt für:

- Rüstungsunternehmen
- Luft- und Raumfahrtprogramme
- Staatlich gesicherte Netze
- Abluftanlagen
- Isolierte Fertigungssysteme
