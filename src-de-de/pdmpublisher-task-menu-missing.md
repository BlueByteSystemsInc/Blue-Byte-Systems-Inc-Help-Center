# Warum fehlt das Aufgabenmenü?

Wenn das **Tasks**-Menü im Datei-Explorer nicht angezeigt wird, können die PDM-Benutzereinstellungen add-ins verbergen.

Öffnen Sie das SOLIDWORKS PDM-Verwaltungstool, öffnen Sie den Benutzereinstellungsdialog und bestätigen Sie, dass add-ins für diesen Benutzer sichtbar ist.

<p align="center">
<img src="https://pdmpublisher.com/help/images/adminsettings.png" alt="PDM Administration user settings" width="800">
</p>

Nachdem add-ins sichtbar sind, öffnen Sie den Datei-Explorer erneut und klicken Sie mit der rechten Maustaste auf eine Datei im Tresor. Die Aufgabe sollte unter **Tasks** erscheinen.
