# Veröffentlichungsprotokolle

Wählen Sie **PDMPublisher > Logs** aus, um die Verarbeitung von steps, erfolgreichen Exporten, Warnungen und Fehlern aus Jobs in der aktuellen SOLIDWORKS-Sitzung zu überprüfen.

![PDMPublisher Logs window filtered to errors](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/logs-errors-filter-20260908.png)

| Kontrolle | Was es tut |
| --- | --- |
| **Find** | Filtert sichtbare Einträge nach Text. |
| Typfilter | Zeigt **All entries**, **Errors**, **Warnings**, **Completed**, **Processing** oder **Skipped** Einträge. |
| Gezeigt / Gesamt / ausgewählte Zählungen | Gibt die aktuell gefilterte Ergebnisanzahl und Auswahlanzahl an. |
| **Follow newest** | Behält den neuesten Protokolleintrag im Blick, während ein Job ausgeführt wird. |
| **Copy selected** / **Copy all** | Kopiert ausgewählte Einträge oder das vollständige Sitzungsprotokoll in die Zwischenablage. |
| **Save...** | Schreibt das komplette aktuelle Sitzungsprotokoll in eine Datei. |
| **Clear** | Entfernt die In-Memory-Einträge nach Bestätigung. |
| **Close** | Schließt das Protokollfenster, ohne die Einträge zu löschen. |

| Seite | Zweck |
| --- | --- |
| [Search and Read Logs](pdmpublishersolidworks-log-search.md) | Filtern Sie Einträge und interpretieren Sie die Eingangsfarben. |
| [Save and Clear Logs](pdmpublishersolidworks-log-files.md) | Speichern Sie das vollständige Sitzungsprotokoll oder löschen Sie die In-Memory-Einträge. |

> [!TIP]
> Speichern Sie das Protokoll sofort nach einem fehlgeschlagenen Job und fügen Sie es bei der Kontaktaufnahme mit `support@bluebytesystemsinc.zohodesk.com` hinzu.
