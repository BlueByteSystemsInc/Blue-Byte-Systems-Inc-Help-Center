# So installieren Sie PDM Add-ins

Die Installation von PDM add-ins von Blue Byte Systems Inc. ist ein einfacher Prozess.

<a id="step-1-locate-the-cex-file"></a>
## Step 1: Suchen Sie die `.cex`-Datei

Nach dem Kauf eines unserer PDM add-ins erhalten Sie eine Bestell-E-Mail mit dem Header * Vielen Dank für Ihr Geschäft! Ihre BLUE BYTE SYSTEMS INC.-Bestellung wurde abgeschlossen*.

> [!NOTE]
> Ihr Konto wird mit der beim Kauf angegebenen E-Mail-Adresse erstellt. Wenn Sie der PDM-Administrator sind und die Bestellung von Ihrer Buchhaltungsabteilung aufgegeben wurde, wenden Sie sich bitte an uns, um Hilfe zu erhalten.



<a id="step-2-download"></a>
## Step 2: Download

1. Laden Sie die Produktdatei (CEX-Datei oder ZIP-Datei) von [Ihrem Konto](https://bluebyte.biz/account) herunter.

2. Einmal heruntergeladen, klicken Sie mit der rechten Maustaste auf die Datei und wählen Sie Eigenschaften.

3. Überprüfen Sie im Fenster Eigenschaften unten die Option Entsperren. Wenn es vorhanden ist, klicken Sie auf Unblockieren und dann auf OK. Dieses step stellt sicher, dass die Datei nicht durch Windows-Sicherheit blockiert wird.

<a id="step-3-open-the-solidworks-pdm-administration-tool"></a>
## Step 3: Öffnen Sie das SOLIDWORKS PDM Administration Tool

1. Suchen Sie die CEX-Datei in Ihrem Downloads-Ordner.

2. Starten Sie das Administrationstool.

3. Melden Sie sich in Ihrem PDM-Tresor an.

<a id="step-4-add-or-update-an-add-in"></a>
## Step 4: Hinzufügen oder Aktualisieren eines Add-ins

1. Gehen Sie im Administrationstool zu Datei > Öffnen ... und durchsuchen Sie den Speicherort der `.cex`-Datei.

2. Wählen Sie die `.cex`-Datei und klicken Sie auf Öffnen. Dadurch wird das Add-in in einem neuen Fenster im Administrationstool angezeigt.

3. Ziehen Sie das Add-in aus dem Fenster in den Add-ins-Knoten in der linken Baumansicht.

Dieser Vorgang ist beim Aktualisieren eines vorhandenen Add-Ins ähnlich. Folgen Sie einfach den gleichen steps, um die alte Version durch die neue zu ersetzen.

<a id="step-5-verify-the-installation"></a>
## Step 5: Überprüfen Sie die Installation

1. Stellen Sie nach der Installation oder Aktualisierung des Add-Ins aus der `.cex`-Datei sicher, dass das Add-in unter dem Add-ins-Knoten erscheint. Stellen Sie sicher, dass die Version mit der Bestell-E-Mail übereinstimmt.

2. Testen Sie die Funktionalität des Add-Ins, um zu bestätigen, dass es korrekt installiert wurde.
