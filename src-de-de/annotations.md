# Anmerkungen Task Page

Verwenden Sie die Aufgabenseite Anmerkungen, um Textnotizen oder Wasserzeichen zu exportierten PDF-Dokumenten hinzuzufügen.

> [!IMPORTANT]
> Dies ist die **PDM task** Annotations Seite. Die Annotationssteuerelemente werden auch vom SOLIDWORKS-Add-in verwendet, aber PDM-Variablen stammen aus dem Vault-Task-Kontext. Siehe [SOLIDWORKS Add-in Anmerkungen](pdmpublishersolidworks_annotations.md).

![PDMPublisher Anmerkungen Seite](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/page-annotations.png)
Jede Anmerkung kann ihren eigenen Text, Formatierung, Position, Blattregel und aktiven Zustand haben.

Die Annotationstabelle ist der große Arbeitsbereich unterhalb der Symbolleiste. Es zeigt die für die Aufgabe konfigurierten Anmerkungen an und lässt Sie auswählen, welche Anmerkung Sie bearbeiten.

<a id="annotation-settings"></a>
## Anmerkungseinstellungen

| Einstellung | Zusammenfassung | Einzelheiten |
|---|---|---|
| Annotation hinzufügen | Erstellen Sie eine neue Annotationsbox. | [Offen](pdmpublisher-annotations/add-annotation.md) |
| Anmerkungen Text | Geben Sie festen Text ein oder verwenden Sie PDM-Variablen. | [Offen](pdmpublisher-annotations/annotation-text.md) |
| SQL Query Platzhalter | Annotationstext aus einer SQL-Datenbank mit dem Dateinamen, dem Teil, der Assembly oder dem Zeichenwert abrufen. | [Offen](pdmpublisher-annotations/sql-query-placeholders.md) |
| Textformatierung | Setzen Sie Schriftart, Größe und Textstil. | [Offen](pdmpublisher-annotations/text-formatting.md) |
| Wasserzeichen | Drehen und verblassen Sie eine Anmerkung für Wasserzeichen-Ausgabe. | [Offen](pdmpublisher-annotations/watermark.md) |
| Aktiv | Fügen oder überspringen Sie eine Anmerkung, ohne sie zu löschen. | [Offen](pdmpublisher-annotations/active.md) |
| Position | Verschieben Sie die Anmerkung oder legen Sie X / Y-Prozentsätze fest. | [Offen](pdmpublisher-annotations/position.md) |
| Blätter | Wählen Sie aus, welche Zeichenblätter die Annotation erhalten. | [Offen](pdmpublisher-annotations/sheets.md) |
