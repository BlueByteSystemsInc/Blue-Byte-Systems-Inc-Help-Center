# Gemeinsame Ressourcen

Öffnen Sie **PDMPublisher > Settings** und verwenden Sie die Gruppe **Shared Resources** für Einstellungen, die von Publishing- und Utility-Workflows wiederverwendet werden.

| Seite | Verwendet für |
| --- | --- |
| [PDM](pdmpublishersolidworks_pdm-settings.md) | Wählen Sie das lokale Gewölbe aus, das von PDM-bewussten Funktionen verwendet wird. |
| [Sprachen](pdmpublishersolidworks_languages.md) | Wählen Sie die Add-in-Schnittstellensprache aus. |
| [File Locations](pdmpublishersolidworks_file-locations.md) | Definiert zusätzliche Orte, an denen verwandte Zeichnungen gefunden werden. |
| [Externe Quellen](pdmpublishersolidworks_external-sources.md) | Speichert wiederverwendbare SQL Server-Abfragedefinitionen. |
| [Fortgeschrittene Formeln](pdmpublishersolidworks_advanced-formulas.md) | Speichert benannte Ausdrücke für Dateinamen, Ordner und Eigenschaften. |

### Fortgeschrittene Formeln

![Erweiterte Formeleinstellungen](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Advanced_Formulas_Default_Light_100.png)
Änderungen werden erst festgelegt, wenn Sie **OK** auswählen. **Cancel** verwirft Änderungen, die seit dem Öffnen des Einstellungsfensters vorgenommen wurden. Verwenden Sie [Einstellungen importieren, exportieren und zurücksetzen](pdmpublishersolidworks_settings-transfer.md), um diese Ressourcen zu sichern oder zu verschieben.

> [!NOTE]
> Eine freigegebene Ressource liefert eine wiederverwendbare Definition. Individuelle profile und befehle entscheiden immer noch, ob sie es verwenden.
