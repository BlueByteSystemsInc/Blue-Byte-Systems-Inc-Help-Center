# Willkommen

PDMPublisher automatisiert das Veröffentlichen und Exportieren von Workflows für SOLIDWORKS und SOLIDWORKS PDM Professional. Es kann PDFs, DXFs, STEP-Dateien, Release-Pakete und andere Ergebnisse mit wiederholbaren Regeln generieren.

<a id="choose-your-pdmpublisher-version"></a>
## Wählen Sie Ihre PDMPublisher Version

PDMPublisher verwendet eine Codebasis und ist in zwei Versionen verfügbar.

<a id="pdmpublisher-for-pdm-professional"></a>
### PDMPublisher für PDM Professional

Das PDM-Task-Add-in läuft innerhalb von SOLIDWORKS PDM Professional. Administratoren konfigurieren zentralisierte Veröffentlichungsaufgaben, die Benutzer manuell, über Workflowübergänge oder nach einem Zeitplan starten können.

- Automatisieren Sie vaultbasierte Export-Workflows.
- Verarbeiten Sie einzelne Dateien, Assemblys und deren Referenzen.
- Steuere Ausgabepfade, Dateinamen, Bedingungen, Anmerkungen und zusammengeführte PDF-Pakete.

[Öffnen Sie die PDMPublisher für PDM Professional Dokumentation](/src/pdmpublisher.html)

<a id="pdmpublisher-for-solidworks"></a>
### PDMPublisher für SOLIDWORKS

Das SOLIDWORKS-Add-in bietet einen interaktiven Publishing-Workflow direkt in der SOLIDWORKS-Desktopanwendung. Es kann auch ohne SOLIDWORKS PDM Professional verwendet werden.

PDMPublisher für SOLIDWORKS ist als SOLIDWORKS Partner Solution Add-in registriert und erscheint unter **Partner Solution Add-Ins** im SOLIDWORKS **Add-Ins** Dialog.

![PDMPublisher für SOLIDWORKS aufgeführt unter Partnerlösung Add-Ins](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/solidworks-partner-solution-add-in.png)
- Exportieren Sie direkt aus SOLIDWORKS.
- Konfigurieren Sie Optionen, Anmerkungen, Bedingungen und Ziele interaktiv.
- Veröffentlichen Sie Dateien auf PDM, Dateiservern oder anderen konfigurierten Speicherorten.

[Öffnen Sie die PDMPublisher für SOLIDWORKS Dokumentation](/src/pdmpublishersolidworks.html)

<a id="supported-formats"></a>
## Unterstützte Formate

PDMPublisher unterstützt PDF, 3D PDF, DWG, DXF, STEP, IGES, Parasolid, STL, eDrawings, HTML, Bildformate und andere CAD-Austauschformate. Siehe [Dateiformate](/src/pdmpublisher-options/file-formats.html) für die vollständige Liste und das Verhalten der Quelldatei.
