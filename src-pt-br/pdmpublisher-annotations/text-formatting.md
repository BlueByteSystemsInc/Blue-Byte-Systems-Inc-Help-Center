# Formatação de Texto

Use controles de formatação para alterar como a anotação aparece no PDF exportado.

![Annotation text formatting in PDMPublisher for SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)

A formatação comum inclui:

- Fonte
- Tamanho do texto
- Negrito
- Itálico

Cada anotação pode usar sua própria formatação. A anotação selecionada é destacada para que você possa ver qual delas está sendo editada.
