# Adicionar uma Nota

Use o botão adicionar anotação para criar uma nova caixa de anotação.

Anotações criadas aqui são armazenadas no **PDMPublisher for SOLIDWORKS Publish profile** selecionado.

![PDMPublisher para o editor de anotações SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Default_Light_100.png)
Novas anotações são adicionadas à visualização da página e podem então ser editadas, posicionadas, habilitadas ou alteradas em uma marca d'água.

Use uma anotação para cada nota separada ou marca d'água que você deseja colocar no PDF exportado.
