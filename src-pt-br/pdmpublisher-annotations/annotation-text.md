# Texto da Anotação

Digite o texto que deve aparecer no PDF exportado.

![Controles de anotação de texto em PDMPublisher para SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Annotations_Dropdown1_Light_100.png)
O texto de anotação pode ser um texto fixo ou valores de propriedade dinâmicos.

O menu de valor inclui propriedades personalizadas SOLIDWORKS e valores suportados do documento ativo.

Use valores dinâmicos quando a anotação deve incluir informações como número de peça, revisão, projeto, cliente, estado ou outros metadados de documento disponíveis para o produto atual.

Para recuperar texto de anotação de um banco de dados SQL, consulte [SQL Consultar Placeholders](sql-query-placeholders.md).
