# Versão e Atualizações

Use o **Updates** CommandManager grupo ou abrir **PDMPublisher > Settings > Support and Updates** para exibir a versão instalada e verificar se uma versão mais recente está disponível.

![Página de suporte e atualizações mostrando versões instaladas e disponíveis](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Support_Updates_Default_Light_100.png)
- **Installed version** é a versão carregada na sessão atual SOLIDWORKS.
- **Latest version** é a versão reportada pelo serviço de atualização.
- **You are using the latest version** significa que a versão instalada corresponde à versão disponível.
- **A new version is available** identifica o lançamento mais recente.
- **Could not check for updates** significa que a verificação de versão online não pôde ser concluída.

Selecione **Check for updates** para atualizar as informações da versão. Uma pré-visualização instalada ou compilação mais recente pode ter uma versão superior à versão atualmente relatada pelo serviço de atualização; leia ambos os valores juntamente com a mensagem de status.

<a id="download-an-update"></a>
## Baixar uma atualização

Quando uma atualização estiver disponível, use a ação de download exibida para abrir o download do instalador em seu navegador.

Fechar SOLIDWORKS antes de executar o instalador. Salve documentos abertos primeiro, e desbloqueie o instalador baixado de suas propriedades de arquivo Windows, se necessário pelo seu ambiente.

Para orientação de instalação, ver [Install PDMPublisher for SOLIDWORKS](pdmpublishersolidworks_installation.md).

A mesma página também fornece ligações **Support**, **Legal notices** e **License agreement**.
