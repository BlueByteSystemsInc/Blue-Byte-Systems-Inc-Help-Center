# Página de Tarefa de Anotações

Use a página de tarefas Anotações para adicionar notas de texto ou marcas de água para documentos PDF exportados.

> [!IMPORTANT]
> Esta é a página de Anotações **PDM task**. Os controles de anotação também são usados pelo SOLIDWORKS suplemento, mas as variáveis PDM vêm do contexto da tarefa do cofre. Ver [SOLIDWORKS Notas de adição](pdmpublishersolidworks_annotations.md).

![PDMPublisher Annotations page](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/page-annotations.png)

Cada anotação pode ter seu próprio texto, formatação, posição, regra da folha e estado ativo.

A tabela de anotações é a grande área de trabalho abaixo da barra de ferramentas. Ele mostra as anotações configuradas para a tarefa e permite selecionar qual anotação você está editando.

<a id="annotation-settings"></a>
## Configuração da Anotação

| Configuração | Resumo | Detalhes |
|---|---|---|
| Adicionar uma Nota | Criar uma nova caixa de anotações. | [Abrir](pdmpublisher-annotations/add-annotation.md) |
| Texto da Anotação | Digite texto fixo ou use variáveis PDM. | [Abrir](pdmpublisher-annotations/annotation-text.md) |
| Locais de Consulta SQL | Recuperar texto de anotação de um banco de dados SQL usando o nome do arquivo, parte, montagem ou valor de desenho. | [Abrir](pdmpublisher-annotations/sql-query-placeholders.md) |
| Formatação de Texto | Definir o estilo de fonte, tamanho e texto. | [Abrir](pdmpublisher-annotations/text-formatting.md) |
| Marca d'água | Rodar e desbotar uma anotação para a saída de marca d'água. | [Abrir](pdmpublisher-annotations/watermark.md) |
| Activo | Incluir ou ignorar uma anotação sem apagá-la. | [Abrir](pdmpublisher-annotations/active.md) |
| Posição | Mover a anotação ou definir as percentagens X/Y. | [Abrir](pdmpublisher-annotations/position.md) |
| Folhas | Escolha quais folhas de desenho recebem a anotação. | [Abrir](pdmpublisher-annotations/sheets.md) |
