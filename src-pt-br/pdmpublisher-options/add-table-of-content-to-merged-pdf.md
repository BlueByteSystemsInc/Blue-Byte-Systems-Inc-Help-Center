# Adicionar tabela de conteúdo ao PDF fundido

![Adicionar tabela de definição de conteúdo em PDMPublisher para SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox10_Add_table_of_content_to_merged_PDF_Light_100.png)
Adiciona uma página de índice gerada ao PDF fundido.

> [!NOTE]
> Esta configuração está disponível tanto no **PDM task** quanto no **SOLIDWORKS add-in** e depende da saída de montagem fundida PDF.

![Customize TOC columns dialog](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_TOC_columns_Default_Light_100.png)

Use isso com [Merge Exportado PDFs em um mestre PDF](merge-exported-pdfs.md). A tabela de conteúdo é criada para o PDF fundido, não para arquivos PDF separados.

Configurações relacionadas:

- [Merge Exportado PDFs para One Master PDF](merge-exported-pdfs.md) cria o mestre PDF que recebe a tabela de conteúdo.
- [Exportar Referências para Formatos de Arquivo Individualmente](export-references-individually.md) é necessário quando se funde PDFs de uma montagem.
- [Formatos de arquivo](file-formats.md) deve incluir `PDF`.
- [PDF Bookmarks](pdf-bookmarks.md) pode adicionar navegação dentro do PDF fundido.
- [Colunas de tabela](table-columns.md) controla as colunas utilizadas em tabelas PDF geradas.
