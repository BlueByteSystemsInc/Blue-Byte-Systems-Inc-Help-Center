# Favoritos do PDF

![PDF bookmarks setting in PDMPublisher for SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Scroll1_Light_100.png)

Define o padrão de favoritos usado no PDF fundido.

> [!NOTE]
> Esta configuração está disponível tanto no **PDM task** quanto no **SOLIDWORKS add-in**. Os valores oferecidos pelo menu de placeholder dependem se o arquivo está sendo processado a partir do PDM ou do documento ativo SOLIDWORKS.

Favoritos tornam PDFs grandes fundidos mais fácil de rever e navegar.
