# Registos de Actividade com Sincronização do Servidor

![Server synced activity logs setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-025-property-server-synced-activity-logs.png)

Envia registros de atividade para o servidor para que possam ser revisados mais tarde para suporte e solução de problemas.

Esta configuração está relacionada com [Registros de Atividade de Vault](turn-on-activity-tracking.md). Activar primeiro os registos de actividade do cofre para que a tarefa tenha registos a enviar.

> [!WARNING]
> Confirme a política da sua empresa antes de habilitar os registros sincronizados com o servidor se nomes de arquivos, caminhos, nomes de variáveis ou histórico de trabalho forem considerados sensíveis.
