# Modo de Vista Rápida (Somente Desenhos)

! [Definição rápida do modo de visualização](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-024-property-quick-view-mode-(drawings-only). png)

Abre desenhos em modo de visualização rápida onde é suportado. Isso pode reduzir o tempo de carga para operações de exportação somente de desenho.

> [!WARNING]
> O modo de visualização rápida usa a visão de desenho em cache. Não pode utilizar os dados mais recentes do modelo referenciado.

Use isso apenas para desenhos extremamente grandes onde o carregamento normal de desenho é muito lento.
