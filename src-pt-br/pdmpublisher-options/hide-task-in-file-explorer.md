# Ocultar Tarefa no Explorador de Arquivos

![Hide task in file explorer setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-018-property-hide-task-in-file-explorer.png)

Oculta o comando de tarefa do menu do PDM File Explorer com o botão direito do mouse.

Por padrão, a tarefa é mostrada no File Explorer sob `Tasks > TaskName`.

Use isto para configurações de tarefas que devem ser executadas apenas a partir de fluxos de trabalho controlados ou contextos de administração.
