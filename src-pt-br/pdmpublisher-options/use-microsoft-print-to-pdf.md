# Usar Microsoft Print To PDF para salvar PDFs

![Use Microsoft Print To PDF setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-032-property-use-microsoft-print-to-pdf-to-save-pdfs.png)

Utiliza o caminho da impressora **Microsoft Print to PDF** do Windows ao criar PDFs.

Use isto apenas quando o caminho normal de exportação PDF não corresponder aos seus requisitos de ambiente ou saída.
