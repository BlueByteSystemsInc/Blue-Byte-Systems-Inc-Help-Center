# Usar esta versão do SOLIDWORKS

![Use this version of SOLIDWORKS setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-034-property-use-this-version-of-solidworks.png)

Seleciona qual versão instalada do SOLIDWORKS deve executar o trabalho de publicação.

![SOLIDWORKS version dropdown](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-dropdown-005-use-this-version-of-solidworks.png)

O ícone SOLIDWORKS é um identificador visual. Selecione um ano instalado no host da tarefa, ou selecione `Latest` para usar a mais nova instalação suportada detectada nesse computador.
