# Exportar Documento Afetado

![Export active document setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-012-property-export-affected-document.png)

Exporta o documento afetado, que é o arquivo de nível superior que acionou a tarefa PDM.

Desactiva isto apenas quando a tarefa deve processar documentos referenciados, mas não o documento de topo.
