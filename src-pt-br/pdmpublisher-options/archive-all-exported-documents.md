# Arquivo Todos os Documentos Exportados (.zip)

![Arquivar todos os documentos exportados que se configuram em PDMPublisher para SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox6_Archive_all_exported_documents___zip__Light_100.png)
Cria um arquivo ZIP contendo os documentos exportados.

> [!NOTE]
> Esta configuração está disponível tanto no **PDM task** quanto no **SOLIDWORKS add-in**.

Use isso para pacotes de lançamento, pacotes de fornecedores ou quando um fluxo de trabalho precisa de um arquivo para passar por revisão.
