# Registos de Actividade do Vault

![Vault Activity Logs setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-035-property-vault-activity-logs.png)

Cria registros detalhados de tarefas que mostram os steps realizados durante a publicação.

Active isto ao validar uma nova configuração de tarefa ou comportamento de exportação de solução de problemas.

Use [Server-Synced Activity Logs](server-synced-activity-logs.md) apenas quando esses registros de atividade também devem estar disponíveis para revisão de suporte.

Use [Pasta de registro (Apenas Vault)](log-folder-vault-only.md) quando os registros de atividade devem ser escritos em uma pasta de cofre específica.
