# Dividir os Corpos

![Split Bodies setting in PDMPublisher for SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox8_Split_bodies_Light_100.png)

Exporta corpos de uma parte multi-corpo para arquivos separados. O nome do corpo é anexado ao nome gerado.

> [!NOTE]
> Esta configuração está disponível tanto no **PDM task** quanto no **SOLIDWORKS add-in**.

> [!IMPORTANT]
> Isto não se aplica às exportações de chapas de metal plano.
