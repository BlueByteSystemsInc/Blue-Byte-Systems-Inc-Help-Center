# Criar Referência do Ficheiro de Destino para o Ficheiro de Origem

![Create reference setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-010-property-create-reference-from-dest-file-to-source-file.png)

Cria uma referência PDM do arquivo de destino exportado de volta para o arquivo fonte.

Isso ajuda os usuários a rastrear um produto exportado de volta ao modelo ou desenho que o criou.
