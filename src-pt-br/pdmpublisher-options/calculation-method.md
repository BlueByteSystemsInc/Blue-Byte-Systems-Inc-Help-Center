# Método de cálculo

![Calculation method setting](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-008-property-calculation-method.png)

Controla como as referências são calculadas para a avaliação de BOM e quantidade.

![Calculation method dropdown](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/options-dropdown-003-calculation-method.png)

Esta configuração está relacionada com [Template](template.md), porque o modelo BOM selecionado fornece a informação de referência e quantidade que o PDMPublisher avalia.

- **As built** usa referências como eram quando a montagem foi registrada.
- **Latest** usa as últimas referências disponíveis em PDM.
