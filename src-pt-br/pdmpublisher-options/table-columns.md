# Colunas da Tabela

![Table columns setting in PDMPublisher for SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Scroll1_Light_100.png)

Controla quais colunas aparecem no índice de conteúdo gerado do PDF.

> [!NOTE]
> Esta configuração está disponível tanto no **PDM task** quanto no **SOLIDWORKS add-in**.

![lista suspensa de colunas de tabela em PDMPublisher para SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_TOC_columns_Dropdown1_Light_100.png)
Opções:

- `Just Name` inclui apenas o nome do arquivo ou item.
- `Name & Quantity` inclui o nome e a quantidade.
- `Custom Columns` usa as colunas configuradas com **Customize Table**.

![Customize table columns dialog](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_TOC_columns_Default_Light_100.png)

Use isso com [Adicionar tabela de conteúdo para PDF](add-table-of-content-to-merged-pdf.md).
