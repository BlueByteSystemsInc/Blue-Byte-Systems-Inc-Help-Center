# Activador de Licença Desligado

O **PDMPublisher Offline License Activator** (ativador.exe) é um utilitário de console seguro e autônomo projetado para ambientes onde a conectividade de internet é restrita ou proibida.

![offlineactivator](https://pdmpublisher.com/help/images/offlineactivator.png)

Esta ferramenta permite que os administradores autorizados consumam uma licença PDMPublisher sem exigir:

- Acesso à Internet
- Validação em nuvem
- Comunicação HTTP externa
- Telemetria ou tráfego de saída

Destina-se especificamente a:

- Empresas de defesa
- Programas Aeroespaciais
- Redes protegidas pelo governo
- Instalações equipadas com ar
- Sistemas de fabrico isolados
