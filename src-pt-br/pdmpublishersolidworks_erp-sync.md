# ERP Sync

Abra **PDMPublisher > Settings > ERP Sync** sob **Integration**.

![ERP Sync página em PDMPublisher para configurações SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_ERP_Sync_Default_Light_100.png)
ERP Sync é reservado para uma integração planejada que sincronizará informações SOLIDWORKS e PDM com sistemas ERP. O comportamento de configuração ainda está sendo definido e a integração não está disponível na versão atual.

> [!IMPORTANT]
> A presença desta página não permite ERP synchronization. Não crie um fluxo de trabalho de produção em torno dele até que um lançamento anuncie que o ERP Sync está disponível.

Use **Search Options** para encontrar a página inserindo `ERP` ou `integration`. **Reset**, **Import** e **Export** aplicam-se ao sistema de configurações, mas ainda não existem opções ERP Sync para salvar.
