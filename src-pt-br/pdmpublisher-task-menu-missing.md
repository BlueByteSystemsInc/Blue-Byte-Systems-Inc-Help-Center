# Por que o menu de tarefas está faltando?

Se o menu **Tasks** não aparecer no File Explorer, as configurações do usuário PDM podem estar escondendo add-ins.

Abra a ferramenta de administração SOLIDWORKS PDM, abra o diálogo de configurações do usuário e confirme que add-ins são visíveis para esse usuário.

<p align="center">
<img src="https://pdmpublisher.com/help/images/adminsettings.png" alt="PDM Administration user settings" width="800">
</p>

Após add-ins são visíveis, reabrir File Explorer e clique com o botão direito de um arquivo no cofre. A tarefa deve aparecer em **Tasks**.
