# Publisher Macros

Abra **PDMPublisher > Settings > Publisher Macros** sob **Integration**.

![Publisher Macros página em PDMPublisher para configurações SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publisher_Macros_Default_Light_100.png)
Publisher Macros é reservado para uma integração planejada que irá agendar trabalhos PDMPublisher para executar automaticamente. O comportamento de configuração ainda está sendo definido e a integração não está disponível na versão atual.

> [!IMPORTANT]
> Publisher Macros é separado da opção **Run macro after saving** em [Save As New](pdmpublishersolidworks_save-as-new.md). Save As New pode executar uma macro SOLIDWORKS existente após criar uma cópia; Publisher Macros é a integração de agendamento planejada.
