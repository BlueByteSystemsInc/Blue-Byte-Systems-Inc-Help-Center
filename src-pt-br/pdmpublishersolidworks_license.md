# Gestão de Licenças

Esta página aplica-se apenas a **PDMPublisher for SOLIDWORKS**. A administração da licença PDM Task pertence à [PDMPublisher separada para documentação PDM Professional](licensespdmpublisher.md#pdmpublisher-for-pdm-professional).

Abra **PDMPublisher > License Key**, ou abra **PDMPublisher > Settings > License Key**.

![License Key page for PDMPublisher for SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_License_Key_Default_Light_100.png)

| Controlo | O que ele faz |
| --- | --- |
| **Company name** | Identifica a empresa associada à licença. Digite exatamente como fornecido. |
| **License key** | Aceita a chave fornecida com o pedido. |
| Botão do olho | Mostra ou esconde temporariamente a chave inserida. |
| **Activate** | Activa a chave neste computador. |
| **Deactivate** | Libera a licença ativa para que possa ser movida para outro computador. |
| **Buy license(s)** | Abre a página de compra PDMPublisher para SOLIDWORKS. |

<a id="activate-a-license"></a>
## Activar uma licença

1. Introduza o **Company name** e o **License key** fornecidos.
2. Selecione **Activate**.
3. Confirme que a área de status relata uma licença ativa.

Desativar a licença antes de substituir o computador ou fazer uma mudança de sistema que pode mudar sua identidade de máquina.

Sem uma licença paga, PDMPublisher para SOLIDWORKS é executado como a edição comunitária. A aplicação exibe os limites atuais da Community Edition na janela de revisão da publicação. O julgamento de 7 dias anunciado em outro lugar neste site de ajuda é para o **PDM Professional Task version** separado, não o SOLIDWORKS suplemento.
