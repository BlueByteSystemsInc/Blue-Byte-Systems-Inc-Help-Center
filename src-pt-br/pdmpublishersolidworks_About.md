Use os grupos **Updates** e **Settings** CommandManager para informações de versão instaladas, verificação de atualização, licenciamento, links de produtos, informações legais e suporte.

| Página | Objecto |
| --- | --- |
| [Versão e Atualizações](pdmpublishersolidworks-updates.md) | Verifique a versão instalada e baixe uma atualização disponível. |
| [Gestão de Licenciatura](pdmpublishersolidworks_license.md) | Ativar ou desativar PDMPublisher para SOLIDWORKS. |
| [Contrato de licença de usuário final](eula.md) | Reveja os termos de licença do produto. |
