# Abrir a Localização de Exportação ao Completar

Habilite **Open Export Location On Completion** para abrir a pasta de saída principal após um trabalho de publicação bem-sucedido.

![Open export location on completion in Publish settings](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Publish_Checkbox2_Open_export_location_on_completion_Light_100.png)

Esta configuração está disponível em **PDMPublisher for SOLIDWORKS**. É útil para um fluxo de trabalho de publicação interativo porque os arquivos gerados estão imediatamente disponíveis para revisão.

> [!NOTE]
> Esta opção abre a principal [Localização da exportação](pdmpublisher-options/export-location.md). Quando locais específicos de extensão estão habilitados, outros formatos podem ter sido escritos para suas pastas de sobreposição configuradas.

Desativar a configuração ao publicar para uma localização de rede que não deve abrir automaticamente ou quando a abertura da pasta interromperia o fluxo de trabalho atual do SOLIDWORKS.
