# Informação da Licença

<a id="pdmpublisher-for-solidworks"></a>
## PDMPublisher para SOLIDWORKS

Abra **PDMPublisher > License Key**, ou abra **PDMPublisher > Settings > License Key**.

![PDMPublisher para a página chave da licença SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/license-community-20260908.png)
| Controlo | O que ele faz |
| --- | --- |
| **Company name** | Identifica a empresa associada à licença. |
| **License key** | Aceita a chave fornecida com o pedido ou julgamento. |
| Botão do olho | Mostra ou oculta temporariamente a chave de licença inserida. |
| **Activate** | Activa a licença inserida neste computador. |
| **Deactivate** | Libera uma licença ativa deste computador. Não está disponível até que uma licença esteja ativa. |
| **Buy license(s)** | Abre a página de compra PDMPublisher. |
| **Request New Trial** | Abre a página de pedido de licença de julgamento. |

<a id="activate-a-solidworks-license"></a>
### Activar uma Licença SOLIDWORKS

1. Digite o **Company name** exatamente como fornecido com a licença.
2. Colar o **License key**.
3. Selecione **Activate**.
4. Confirme que a área de status relata uma licença ativa.

Selecione **Deactivate** antes de mover uma licença para outro computador, substituindo o computador, ou fazer uma mudança de sistema que possa afetar a identidade da máquina.

<a id="community-edition"></a>
### Edição da Comunidade

Sem uma licença paga ou de teste ativada, a página identifica os limites da edição comunitária:

- PDF, DXF, e STEP saída apenas.
- Até cinco referências por execução.
- Configurações Premium, incluindo locais de exportação por formato de arquivo, não estão disponíveis.

Use **Request New Trial** para avaliar os recursos premium, ou veja [Obter um teste de 7 dias](pdmpublishertrial.md).

<a id="pdmpublisher-for-pdm-professional"></a>
## PDMPublisher para PDM Professional

<a id="managing-a-license"></a>
### Gerenciar uma Licença

Sua licença é feita de um **secret key** que lhe foi fornecido no * email de ordem*.

Sua licença permite que você use o PDM Publisher:

- Durante uma duração determinada.
- Vários domínios (número de cofres onde você pode instalar o suplemento).

Para gerenciar sua licença:

- Entre em seu cofre da ferramenta de administração PDM.
- * Botão direito* o suplemento do nó **Add-ins** e *selecionar * ***Manage license...** *

<p align="center">
<img src="https://pdmpublisher.com/help/images/pdmpublisher_license_manager.png" alt="PDMPublisher license manager dialog" width="800">
</p>

<a id="activating-a-pdm-professional-license"></a>
### Activando uma Licença PDM Professional

Para ativar uma licença:
- *Enter* your license key and *click* ***Activate*** to consume the license from the **[previous step](#managing-a-license)**.

<a id="deactivating-a-pdm-professional-license"></a>
### Desactivando uma Licença PDM Professional

Para desativar uma licença:
- *Clique* ***Deactivate*** no gerenciador de licenças para parar de usar a licença no cofre logado.

<a id="reactivate-a-pdm-professional-license"></a>
### Reactivar uma Licença PDM Professional

Para reativar a licença, siga estas instruções:

1. *Abrir* a ferramenta de administração PDM.
2. *Expandir* os nós de adição e *clique direito* em PDMPublisher.
3. * Clique * * **Manage license…** *
4. *Enter* sua chave de licença. Se você estiver reativando a mesma chave de licença após expirar, você não precisa entrar novamente na chave de licença.
5. Clique em **Activate**.
6. A sua nova data de validade deverá aparecer.
