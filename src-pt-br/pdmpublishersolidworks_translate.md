# Traduzir

Abra **PDMPublisher > Settings > Translate** sob **Utilities**.

![Translate page in PDMPublisher for SOLIDWORKS settings](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Settings/Settings_Translate_Default_Light_100.png)
Traduzir é reservado para um fluxo de trabalho planejado para traduzir propriedades, nomes de recursos e outro texto de documento SOLIDWORKS. Comportamento de tradução e configurações ainda estão sendo definidas, e o comando não está disponível na versão atual.

O comando **Translate** CommandManager desativado e esta página de configurações indicam a localização planejada do recurso. Eles ainda não realizam a tradução.
