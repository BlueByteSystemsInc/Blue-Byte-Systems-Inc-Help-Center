# Campos de Condição

Cada condição compara um valor de arquivo com a regra que você define.

![Linha de classificação em PDMPublisher para SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Default_Light_100.png)
| Campo | Significado |
|---|---|
| Variável | Valor variável ou incorporado para verificar. |
| Tipo de Condição | A regra de comparação a aplicar. |
| Valor | O valor a comparar. |
| Configuração | Configuração de onde ler o valor. Deixe-o vazio para usar a configuração SOLIDWORKS referenciada ou ativa onde suportado. |

Comparações de texto não são sensíveis a maiúsculas.
