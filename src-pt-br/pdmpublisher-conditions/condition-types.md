# Tipos de Condição

Condição Tipo controla como PDMPublisher compara a variável selecionada com o valor inserido.

![Selecção do tipo de condição em PDMPublisher para SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Dropdown2_Light_100.png)
| Tipo | Usar quando |
|---|---|
| Texto igual / não igual | O valor deve corresponder ou não ao texto específico. |
| O texto contém / não contém | O valor só precisa incluir ou evitar parte do texto. |
| Comprimento do texto | O comprimento do texto importa. |
| Comparação dos números | O valor é um número. |
| Comparação de datas | O valor é uma data. |
| Sim/Não comparações | O valor é uma variável sim/não. |

O texto igual suporta `*` como um wildcard.
