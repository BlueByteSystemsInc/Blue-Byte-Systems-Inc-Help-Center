# Adicionar Condições e Grupos

Use condições para incluir ou excluir arquivos antes de PDMPublisher exportá-los.

Os grupos de condição criados aqui são armazenados no **PDMPublisher for SOLIDWORKS Publish profile** selecionado.

![Conditions page controls in PDMPublisher for SOLIDWORKS](https://pdmpublisher.com/help/images/pdmpublisher/solidworks/ui-preview/Publish/Publish_Conditions_Default_Light_100.png)

Grupos de condição podem usar lógica AND ou OR. Grupos aninhados permitem construir regras mais detalhadas.

Use o botão grupo para adicionar outro grupo AND/OR. Use o botão condição para adicionar uma regra dentro do grupo selecionado.

Condições individuais e grupos podem ser ativados ou desativados com a caixa de seleção à esquerda.
