# Recursos Compartilhados

Abra o **PDMPublisher > Settings** e use o grupo **Shared Resources** para configurações reutilizadas por fluxos de trabalho de publicação e utilidade.

| Página | Usado para |
| --- | --- |
| [PDM](pdmpublishersolidworks_pdm-settings.md) | Selecciona o cofre local utilizado pelas funcionalidades do PDM. |
| [Línguas](pdmpublishersolidworks_languages.md) | Selecciona o idioma da interface suplemento. |
| [Localizações dos ficheiros](pdmpublishersolidworks_file-locations.md) | Define locais adicionais usados para encontrar desenhos relacionados. |
| [Fontes externas](pdmpublishersolidworks_external-sources.md) | Armazena definições reutilizáveis de consulta SQL Server. |
| [Formulas avançadas](pdmpublishersolidworks_advanced-formulas.md) | Armazena expressões nomeadas para nomes de arquivos, pastas e propriedades. |
