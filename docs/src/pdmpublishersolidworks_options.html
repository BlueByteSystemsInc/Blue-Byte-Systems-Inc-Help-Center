Options Tab

The PDMPublisher tab contains the output and processing settings stored in the selected profile.

Use the focused pages beneath Options Tab in the TOC:

Category Pages
Profiles and presets Profiles, Presets, and Share Profiles Using a PIN
Output paths and names Export Location, Filename, File Formats, Open Export Location, and Archive Exported Documents
Assembly and references Export References Individually and Ignore Sub-Assembly Children
Configurations Convert Multiple Configurations
Drawing sheets and PDFs Sheets to Export, Sheet Name Pattern, Merge Exported PDFs, Table of Content, Table Columns, and PDF Bookmarks
Manufacturing outputs Sheet Metal Flat Pattern DXF and Split Bodies
Execution Run a Publish Job
Note

Task-only settings are intentionally excluded from this SOLIDWORKS add-in section. See PDM Task vs SOLIDWORKS Add-in when a setting shown in the PDM Administration tool is not present here.

Use the Placeholder Reference when constructing output paths, filenames, sheet patterns, annotations, or conditions.
