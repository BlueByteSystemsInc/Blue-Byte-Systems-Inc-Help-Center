PDMPublisher Video Demos

See how PDMPublisher automates common SOLIDWORKS and SOLIDWORKS PDM Professional publishing workflows.

Export Each SOLIDWORKS Configuration as a Separate File

Automatically split and export SOLIDWORKS configurations. Each configuration can be published as a separate file with its own naming rules and output folder.

Export SOLIDWORKS Parts and Assemblies as HTML

Share SOLIDWORKS models in a web browser. PDMPublisher exports parts and assemblies as lightweight HTML files for design reviews and vendor communication.

Add Annotations to Exported PDFs

Add intelligent annotations to exported PDFs. Pull property data, part numbers, revisions, and other values directly from the source file and position them on the finished PDF.

Export Assembly References to STEP

Automate STEP exports for an assembly and its references. PDMPublisher can check generated files into a PDM vault or export them outside PDM using dynamic paths and filenames.

Export Sheet-Metal Flat Patterns

Generate manufacturing-ready 1:1 DXF flat patterns for sheet-metal parts without manually saving or renaming each file.

Run PDMPublisher as a PDM Task

Automate exports directly from a SOLIDWORKS PDM Professional vault. Configure PDF, DXF, STEP, and other outputs with dynamic folder routing, filenames, and assembly-reference processing.
