Publish from the document you are working on

Run repeatable publishing and document-management workflows directly from the SOLIDWORKS CommandManager. Reusable profiles keep file formats, names, destinations, references, sheets, annotations, and conditions consistent.

Core workflows

Publish

Export the active document and selected references with a reusable profile.

Save As New

Create a controlled copy with new names, properties, and related drawings.

Clone Tree

Copy and rename a complete assembly structure while preserving references.

Property Doctor

Review and update document, configuration, and cut-list properties.

BOM Manager

Review, group, filter, and exchange assembly BOM data.

ERP Sync

Synchronize reviewed items, properties, files, and manufacturing BOMs.

Common outputs

  • PDF and merged PDF packages
  • STEP, IGES, and Parasolid
  • DWG and flat-pattern DXF
  • eDrawings and image formats

More control when needed

Use profiles, annotations, conditions, and Publisher Macros to standardize advanced jobs without rebuilding them each time.
