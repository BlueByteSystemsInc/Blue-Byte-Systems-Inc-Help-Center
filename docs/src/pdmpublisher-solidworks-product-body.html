SOLIDWORKS task-pane add-in

Publish deliverables directly from SOLIDWORKS

PDMPublisher for SOLIDWORKS gives designers and engineers publishing and document utilities directly inside SOLIDWORKS. Open a drawing, part, or assembly, choose a reusable profile, and publish the deliverables your team needs without rebuilding the export steps by hand.

This version is built for interactive publishing from the active SOLIDWORKS session. Profiles store output locations, filename rules, formats, reference handling, drawing sheet behavior, annotations, conditions, and other publishing options.

Best fit

Use PDMPublisher for SOLIDWORKS when publishing should start from the document currently open in SOLIDWORKS and be controlled from the SOLIDWORKS CommandManager or Tools menu.

Different from the PDM task product

This version stores settings as reusable profiles. If publishing should be launched by SOLIDWORKS PDM Professional as a task, workflow action, or schedule, use the PDM task version instead.

Common publishing workflows

  • Create a supplier package with PDF drawings, STEP models, and a ZIP archive from the active assembly.
  • Export manufacturing DXFs from sheet-metal parts using 1:1 flat patterns, bend lines, and controlled file names.
  • Publish drawing PDFs with watermarks, QR codes, custom properties, selected sheets, bookmarks, and a table of contents.
  • Generate separate deliverables for multiple configurations while filtering out configurations that should not be released.
  • Maintain separate profiles for prototype, released, customer, fabrication, and purchasing output packages.
  • Create a renamed copy of a part, assembly, or drawing with Save As New while carrying its associated drawing and applying property cleanup.
  • Clone a complete assembly tree into a new project structure and optionally package companion PDF, DXF, or STEP files in a ZIP archive.
  • Review and normalize custom properties across an assembly with Property Doctor before publishing or copying it.
  • Standardize BOM columns, hierarchy, grouping, and component exclusions with BOM Manager.
  • Push reviewed products, mapped properties, attachments, and manufacturing BOMs to ERPNext or Odoo, and review proposed property changes before Pull writes to SOLIDWORKS.
  • Automate supported Save As New, Property Doctor, Clone Tree, and ERP Sync workflows through Publisher Macros.

Why teams use it

Engineering teams often need the same outputs again and again: a PDF for review, a DXF for sheet metal, a STEP file for a supplier, or a drawing package for manufacturing. PDMPublisher for SOLIDWORKS turns those repeated export routines into profile-based actions that are easier to run and easier to standardize.

The result is less manual saving, fewer missed configurations or sheets, and a cleaner handoff from design work to the teams that depend on accurate published files.
