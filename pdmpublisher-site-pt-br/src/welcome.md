# Boas-vindas

PDMPublisher automatiza fluxos de trabalho de publicação e exportação para SOLIDWORKS e SOLIDWORKS PDM Professional. Ele pode gerar arquivos PDFs, DXFs, STEP, pacotes de lançamento e outros entregables usando regras repetitivas.

<a id="choose-your-pdmpublisher-version"></a>
## Escolha a sua versão PDMPublisher

PDMPublisher usa uma base de código e está disponível em duas versões.

<a id="pdmpublisher-for-pdm-professional"></a>
### PDMPublisher para PDM Professional

O complemento de tarefa PDM é executado dentro do SOLIDWORKS PDM Professional. Os administradores configuram tarefas de publicação centralizadas que os usuários podem lançar manualmente, a partir de transições de fluxo de trabalho, ou em um cronograma.

- Automatize fluxos de trabalho de exportação baseados em cofre.
- Processe arquivos individuais, conjuntos e suas referências.
- Controle caminhos de saída, nomes de arquivos, condições, anotações e pacotes PDF fundidos.

[Abrir o PDMPublisher para documentação PDM Professional](/src/pdmpublisher.html)

<a id="pdmpublisher-for-solidworks"></a>
### PDMPublisher para SOLIDWORKS

O suplemento SOLIDWORKS fornece um fluxo de trabalho de publicação interativo diretamente dentro do aplicativo de desktop SOLIDWORKS. Também pode ser usado sem SOLIDWORKS PDM Professional.

PDMPublisher para SOLIDWORKS é registrado como um SOLIDWORKS Partner Solution suplemento e aparece em **Partner Solution Add-Ins** no diálogo SOLIDWORKS **Add-Ins**.

![PDMPublisher para SOLIDWORKS listado na solução do parceiro Add-Ins](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/solidworks-partner-solution-add-in.png)
- Exportar diretamente da SOLIDWORKS.
- Configure opções, anotações, condições e destinos de forma interativa.
- Publique arquivos em PDM, servidores de arquivos ou outros locais configurados.

[Abrir o PDMPublisher para a documentação SOLIDWORKS](/src/pdmpublishersolidworks.html)

<a id="supported-formats"></a>
## Formatos suportados

PDMPublisher supports PDF, 3D PDF, DWG, DXF, STEP, IGES, Parasolid, STL, eDrawings, HTML, image formats, and other CAD interchange formats. See [File Formats](/src/pdmpublisher-options/file-formats.html) for the complete list and source-file behavior.
