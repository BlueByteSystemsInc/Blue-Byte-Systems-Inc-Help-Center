# Bienvenue

PDMPublisher automatise la publication et l'exportation des workflows pour SOLIDWORKS et SOLIDWORKS PDM Professional. Il peut générer des fichiers PDF, DXF, STEP, des paquets de version et d'autres livrables en utilisant des règles répétables.

<a id="choose-your-pdmpublisher-version"></a>
## Choisissez votre version PDMPublisher

PDMPublisher utilise une base de code et est disponible en deux versions.

<a id="pdmpublisher-for-pdm-professional"></a>
### PDMPublisher pour PDM Professional

L'complément de la tâche PDM fonctionne à l'intérieur de SOLIDWORKS PDM Professional. Les administrateurs configurent des tâches de publication centralisées que les utilisateurs peuvent lancer manuellement, à partir de transitions de workflow, ou sur un calendrier.

- Automatiser les flux de travail d'exportation basés sur le coffre-fort.
- Traiter les dossiers, les assemblages et leurs références.
- Contrôler les chemins de sortie, les noms de fichiers, les conditions, les annotations et les paquets PDF fusionnés.

[Ouvrir le PDMPublisher pour la documentation PDM Professional](/src/pdmpublisher.html)

<a id="pdmpublisher-for-solidworks"></a>
### PDMPublisher pour SOLIDWORKS

L'complément SOLIDWORKS fournit un workflow de publication interactif directement à l'intérieur de l'application de bureau SOLIDWORKS. Il peut également être utilisé sans SOLIDWORKS PDM Professional.

PDMPublisher pour SOLIDWORKS est enregistré en tant qu'ajout à SOLIDWORKS Partner Solution et apparaît sous **Partner Solution Add-Ins** dans la boîte de dialogue SOLIDWORKS **Add-Ins**.

![PDMPublisher pour SOLIDWORKS listé sous Solution Partenaire Add-Ins](https://pdmpublisher.com/help/images/pdmpublisher/screenshots/solidworks-partner-solution-add-in.png)
- Exporter directement à partir de SOLIDWORKS.
- Configurer les options, les annotations, les conditions et les destinations de manière interactive.
- Publier les fichiers sur PDM, serveurs de fichiers ou autres emplacements configurés.

[Ouvrir le PDMPublisher pour la documentation SOLIDWORKS](/src/pdmpublishersolidworks.html)

<a id="supported-formats"></a>
## Formats pris en charge

PDMPublisher prend en charge PDF, 3D PDF, DWG, DXF, STEP, IGES, Parasolid, STL, eDrawings, HTML, formats d'images et autres formats d'échange CAO. Voir [Formats de fichiers](/src/pdmpublisher-options/file-formats.html) pour la liste complète et le comportement du fichier source.
